> 状态: **落地记录**（2026-10-19）· 上游: `docs/253`（七级）· `docs/262`（LSPE）
> · `docs/229` §3.2（默认产物逐字节相同 —— 这一页记的是它**被绕过的那一次**）
> · `docs/210` §6.2（LGC 与 LMS 是同一张图的两个方向）· 里程碑 **0.1.5.1**

## 1. 七级：落地物与判据

| 级 | 落地物 | 判据 | 形状 |
|---|---|---|---|
| **1 检查器** | E028（字面量越界，**语言规则**，默认就发）、E029（用完再放，`lms_check` 管） | `lomentc_test` 的 E028/E029 两条 · `loment_rule_parity` 两条探针 | 编译期 |
| **2 管理器** | `lms_report()` + `--lms-report PATH`：这份单元的**内存图** | `loment_lms_test::test_manager_report_lists_every_alloc_site`（与 `gc_ladder.total_sites` 对账） | **编译期**（改判，§3.1） |
| **3 保障器 A**（用尽） | `alloc` 分配不出时**先收一次再试**；重试标记是本帧的 `alloca` | `lomentc_test` 网格 3×2 · `loment_p8_test` 三格逐字节 | 运行期，无新符号 |
| **3 保障器 B**（越界） | **检测那一半**：`alloc(<常量>)` 直接发出的 `load8`/`store8` 上一条内联界检查 | `lomentc_test::test_lms_g1_site_*` · `loment_p8_test::test_m93_*` | 运行期（改判，§3.3） |
| **4 拒绝器** | 越界时**跳过那一条访存**（`load8` 取 0、`store8` 不发生），程序继续 | `test_lms_rejector_keeps_running_and_crash_stops_it`（**跑出来的** rc=1） | 运行期 |
| **5 崩溃器** | 拒不了就 `llvm.trap`（`@__loment_abort`）—— 进程自己退出，由 OS 收尸 | 同上（`close lms_reject` ⇒ rc=132 = SIGILL） | 运行期 |
| **6 重启器** | `restarter/loment-restart.c` —— **C 写的**，死了拉起来，崩到上限就停 | `test_restarter_brings_the_program_back`（真编真跑） | 进程外 |
| **7 最小子集** | 自举种子 + **它的名字、字节数、哈希**（§4） | `test_the_floor_is_named_and_sized` | 进程外 |

**梯子的方向**（`docs/253` §5.0）：每一级都是上一级失效之后的退路。所以在**同一个访存点**上，
第 3 级先发检查，第 4 级跳过，第 5 级才死 —— 顺序是三档开关
（`lms_guard` / `lms_reject` / `lms_crash`）**叠出来**的，不是一件事的三种写法。

## 2. `lms` 这一维：档 + 七个细开关

`docs/253` §11.3/§11.4 的裁定照做，取值的落法见 §3.5：

```
lms_full              七级全开（默认，不带 `_admin`）
lms_forensic_admin    1+2+3+4
lms_daily_admin       1+3+4
lms_manage_only_admin 2
```

* **默认是满的**，写档是**降级** —— 这一维的方向与别的维相反。
* **档铺初值、显式开关覆盖**，落点在**预扫期**：`_seed_lms()` 先铺、`_collect_switches()`
  后收。初值的行号记 `0`（"不是写的"），于是显式写一次**不会**被判成"写了两遍"。
* **七个细开关由编译器定义**，用户不必（也不能）用 `set choose` 去"定义"它们。
* 产物里可判：Potato **v17** 的 `lms_levels`（七个布尔）记的是**最后**的结果；
  `lms` 那个字段记的是"想要哪一档"。
* 两档同时写仍然是**错误**（逐维的"只能声明一次"没有变）。

## 3. 三个改判（每一处都写清"为什么不按初稿"）

### 3.1 第 2 级是**编译期**的内存图，不是运行期堆快照

初稿那句「详细输出所有内存（占地极大）」**不是一个能实现的句子**（#386 自己就是这么写的）。
把它变成可实现的句子有两条路，这一轮选了第一条：

1. **编译期内存图**：`--lms-report` 列出每一处 `alloc` 站点（单元、函数、行、尺寸），
   加上 arena 上限与这一档的七级集合。
2. 运行期堆快照：要一个**有状态**的运行期，而默认档是 `no_runtime`（`docs/175` §3.6
   是一条**保证**），且它与 §13.2「默认产物不带一个新符号」直接打架 —— 除非把管理器做成
   默认关，可裁定说默认是满档。

⚠ **它因此不是**：不是堆快照、没有时间轴、说不了「这块在 S12 被释放」。`docs/253` §5.2
的**报错器**那一格（跨时间轴的见证）仍然**是空的** —— 这一页不冒充它。

**代价**：第 2 级不再是"占地极大"。那句定位是初稿给它的，改判之后它变成**几乎不要钱**。
这改变了这一级的性格，所以写在这里，而不是悄悄改一行表格。

### 3.2 第 5 级"退出所有 Loment 进程"在 `no_std` 下**表达不出来**

硬边界照 `docs/253` §5.5 写死：`no_std` 下只有 syscall，**杀不了别的进程**。
可表达的形态是**自己退出、让 OS 收尸**（父进程是第 6 级那个重启器）。
`llvm.trap` 就是那个形态：进程被 `SIGILL` 打死，父进程看得见。

⚠ **不主张**"退出所有进程"。多进程 / 进程组 / 检查点都没有做。

### 3.3 第 3 级入口 B 只落了**检测那一半**

`docs/253` §5.3 的入口 B 有两半：检测（每块的边界）与响应（隔离被踩块、从影子重建、弃用）。
这一轮落了**检测**，而且**只对一种指针**：

* `let p: ptr = alloc(<编译期常量>)` **直接**发出的指针 —— 它的界就是那个常量（g1 格）；
* 过了 `ptr_add` 的、切片的、结构体字段的 —— **不发检查**。保守地不发，比把块里的数据
  当块长读安全（§5.3 入口 B 的准备 ③ 原话）。

**响应**那一半落在第 4/5 级：跳过或退出。**从影子重建没有做** —— 那份状态一个字节都没有，
`docs/253` §11.2 的"按级给"允许它有，但这一轮没给它。

### 3.4 四个官方组合**就是四个档名**，没有单独的 `chooseset` 文件

`docs/253` §11.4 ② 原本要给四个组合各写一个 `chooseset` 文件（`addin lms_daily` 之类），
再用一行 `addin` 拉进来。落地时看清楚了：**那一层是多余的**。

* 组合必须在**预扫期**落定（开关决定"解析前抹不抹"），而 `addin` 的定义**那时还没读到**
  —— 这正是 §11.4 那条叠加规则要解决的事；
* 既然档 → 七开关的表已经在编译器里，**写一个档名就等于写四个组合**——
  `choose lms_daily_admin` 已经**就是** `addin lms_daily` 的全部内容。

⇒ 四个组合 = 四个档名。`chooseset` 那套机制原样保留，给**用户自定义**的组合用。
**代价**：这四个名字不再是"可以改的文件"，而是 `CORE_DIMS` 的一部分 —— 改它们要动两套
实现（同 `CORE_DIMS` 的纪律）。这是**换来**的：组合与档不可能漂开。

### 3.5 所以 `lms` 的四个档名带 `_admin`

`docs/262` §10.1 立的仓级规则是「**关闭关键安全系统的取值必须带 `_admin`**」，
并留了一张"待迁移"的表（`lms_close` → `lms_close_admin`）。这一轮把它结掉了，
但**不是改名**：`lms_close` / `lms_open` 被**档名取代**，而"关"这个取值**不存在了** ——
`lms_manage_only_admin` 不是"关掉安全"，是"只剩管理器"。

规则本身第一次变成**机械检查**：`LMS_TIERS` 在导入期逐行核，`loment_lms_test` 也钉着。
**满档不带 `_admin`**（它不是关闭）。

## 4. 信任地板（第 7 级）：给它名字与数

地板不是一个文件，是一句话：

> **重启器 + 最小子集 + 编它们的那些工具链。**

单独一个 C 重启器回答不了 Thompson 那道题 —— 编它的那个 C 编译器又怎么信。
所以地板的准确陈述必须把三样都说出来，否则它就是一块**没被标注的地板**（`docs/253` §1.2）。

最小子集是 `loment/build/selfhost_driver.ll`，它的数与哈希写在下面这一块里，
`loment_lms_test::test_the_floor_is_named_and_sized` 每次重算并与这一块比 ——
**这一块因此不能过期**：

```
artifact: loment/build/selfhost_driver.ll
bytes: 4411591
sha256: 04f68ddadb4b9c35c325acb8a4ce58320e9af33448b5b377aa6367d8ce52c2cd
```

⚠ **边界（照 `docs/253` §5.5 那条）**：本仓的自举链证明的是「**种子 == 参考实现的产物**」，
**不是**「种子能自己长出参考实现」。这两件事不同，这一页不混。

## 5. "跳过之后没更坏"——第 4 级那条最难的判据是怎么证的

`docs/253` §5.4 说这条判据"今天不存在"，而它不存在是因为**没有那个机制**。
现在有机制了，判据这样写（`test_lms_rejector_keeps_running_and_crash_stops_it`）：

同一份源，界内写 `1`、界外写 `7`、界外读一次、把两次读加起来 **退出**：

| 档 | 结果 | 说明 |
|---|---|---|
| 默认满档 | **rc = 1** | 界外写没发生、界外读回 0 ⇒ 答案**恰好**是界内那一半 |
| `close lms_reject` | **rc = 132**（SIGILL） | 拒不了就崩 —— 不是"算出一个错答案" |

**"没更坏"的操作定义就是这两行**：被拒的那一条指令**没有发生**，而**其余的计算照旧**。
⚠ 它不是"程序语义没变" —— 跳过**就是**改变语义（§5.4 原话：这是唯一会改变语义的一级）。

## 6. 默认 = 满档：实测的代价（`docs/253` §13.3 那张表要求的）

| 面 | 估的数（§13.3，2026-10-15） | **实测**（2026-10-19） |
|---|---|---|
| 默认产物的字节 | "必须变" | **变**：`gc_auto` 每处 `alloc(<常量>)` 派生的 `load8`/`store8` 多一条 `icmp` + 两个块 |
| 新符号 | "一个都不许" | **零**：入口 A 的标记是 `alloca`；g1 检查是纯指令 |
| 默认产物"逐字节相同"那条判据（`docs/229` §3.2） | 会被绕过 | **被绕过**，留痕在 `docs/229` §3.2 |
| 孪生判据 | 不会红（两边一起变） | **确实没红** —— 32/33 → 33/33 |
| 冻结了旧产物字节的夹具 | 要逐条改 | `loment_p8_test` 那一格改成断言 `%lmsretry` 与检查的形状 |

⚠ **`lomentc_test.py` 那条「默认档一点 `@__loment_` 痕迹都没有」照旧成立** ——
这是 §13.2 那条约束保下来的第三格，也是这一轮**最值钱的**一格。

## 7. 与 LSPE 的兼容（`docs/262`）

* **`_admin` 规则**：见 §3.5。这是两边第一次真正接上 —— 之前 `docs/262` §10.1 只是
  把 `lms` 列在"待迁移"里。
* **台账里的来源**：LSPE 的站点普查把 `index` 站点的来源记成 `lms(g0)`（`docs/262` §5.1）。
  LMS 这一轮**没有改那个口径**：g1 检查发在 `load8`/`store8` 上，而 LSPE 现在数的是
  `guard` 与 `index` 两类站点 —— 两者是**不同层的证据**，硬把 g1 塞进 `lms(g0)` 会让
  "这个站点凭什么放行"这句话变成两种意思。**接上它们要单独一格**，写在下面。
* ⚠ **没做**：LSPE 的义务系统不认识 g1。今天 `lms_guard` 发出的检查**不进台账**。
  这是 0.1.5.1 之后的第一件兼容工作，不是"顺手就能加"的：台账的 `Site` 是内容寻址的，
  而 g1 检查的站点 id 还没定义。

## 8. 我不主张

1. **不主张七级都"完整"**。第 2 级改判成编译期；第 3 级入口 B 只有检测；
   第 4 级的"跳过"只覆盖**一种**指针；第 6 级只做单进程重启。
2. **不主张"跳过"是安全的**。它是**改变语义**的那一级，`docs/253` §5.4 自己就这么说。
   默认满档之下它**默认开着** —— 这是裁定的直接后果，不是这一页的推荐。
3. **不主张第 5 级"退出所有进程"**（§3.2）。
4. **不主张地板能被验证**：种子 == 参考实现的产物，不等于种子能长出参考实现（§4）。
