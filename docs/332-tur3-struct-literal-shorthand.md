# 332 · Tur 2026.3：结构体字面量字段简写

> 状态：**已落地**（2026-11-10，两套实现）· 版次：`tur2026.3`
> 上游：`docs/296` §5（Tur 3 的语法优化清单）· `standard/LLS.md` §8.10 / §12.9
> 判据：`loment_grammar_test::test_tur2026_3_struct_literal_shorthand`、
> `loment_p8_test::test_m98_struct_literal_shorthand_twin`

---

## 1. 语法

```rust
module short

struct S { a: u32, b: u32 }

fn main() -> u32 {
    let a: u32 = 1;
    let b: u32 = 2;
    let s: S = S { a, b };      // ≡ S { a: a, b: b }
    return s.a + s.b;
}
```

- 字段可以只写**标识符**；值就是同名的那个绑定。
- 显式与简写可以混用：`S { a, b: 2 }`。
- 缺字段 / 重复 / 未知字段仍然是 **E015**，判据不变。
- 名字未声明仍然是 **E002**（简写值照常走一遍表达式检查）。

## 2. 版次

**只在 `tur2026.3` 及以后收。** `tur2026.1` / `tur2026.2` 里 `S { a }` 仍是
`期望 :，得到 ','` 的语法错 —— 两个封版版次一个字节都不动。

它不是纯糖意义上的"等长改写"：AST 里直接长出 `(a, Ident(a))`，所以
**产物与显式写法逐字节相同**（同一版次，版次元数据也相同）。

## 3. 两套实现

| 侧 | 落点 |
|---|---|
| 参考实现 | `tools/lomentc.py` 的 `parse_atom` 结构体字面量分支：`profile in TUR3_PLUS` 且字段名后是 `,` / `}` 时，值是 `Ident(字段名)` |
| 自举 checker | `checker.lomt` 的 `chk_sfield_head`：字段名位置收 `f:` 与 2026.3+ 的 `f,` / `f}`；重复字段、缺字段、值表达式各走原来的路 |
| 自举 codegen | `codegen.lomt` 的 `let_struct_lit`：`CG_PROF >= 2` 时，裸字段名的值 token 就是字段名 token |

自举侧两处都用 **prof 编号** 判断版次（`0/1/2`），与 `lgc`、`lifetime` 同一条路。

## 4. 判据

* `loment_grammar_test`：2026.3 下简写与显式写法的 IR **完全相同**；
  `tur2026.2` 钉住时**拒**。
* `loment_p8_test` M98：同一份简写程序，参考实现与自举驱动的 IR **逐字节相同**；
  显式版与简写版相同；`tur2026.2` 两边都拒。

## 5. 这一批的后续顺序

`docs/296` §5 的语法优化按"改动面从小到大、每步两套实现 + 判据"推进：

1. **结构体字段简写**（本篇，已落）；
2. `for i, x in xs`（**已落**，`docs/333`）/ `for x in <call>`（**已落**，`docs/334`；
   数组字面量与其它表达式仍未做）；
3. `if` / `match` 当表达式（**已落**：`if` 见 `docs/335`，`match` 见 `docs/336`）；
4. 字符串插值（**已落**，`docs/341`；前置的 `str_num` 见 `docs/337`；
   宽度 / 补零 `{x:>5}` / `{x:05}` 同篇 §6）；
5. `args(i)` 内建（**已落**，`docs/348`）；
6. `const NAME: str = "..."`（**已落**，`docs/342`）；
7. `catch |e| { … }` / `catch return`（**已落**，`docs/343`）；
8. `:=` / `auto` 局部类型推断（**已落**，`docs/347`；动类型系统，单独一笔）。

每一步只在 2026.3+ 收，旧版次保持原样；语义与产物对齐由孪生判据钉住。

## 6. 明确不做

* 不改 `fn` / `def`（2026-11-09 的短声明裁定）；
* 不做字段默认值、展开语法 `..`、结构体更新语法 —— 那些不在 `docs/296` §5 的清单里；
* 不改结构体字段的类型限制（仍是标量面，见 `docs/299`）；
* `fmt` / `doc` / LSP 对这条新拼法没有专门判据：它们按 token 走，不会拒绝，
  但也没有"格式化成简写/展开成显式"的规则。要加规则时另开一笔（`docs/182` §1.9
  的消费者清单）。
