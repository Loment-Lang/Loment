## 0. 先说清楚今天有什么、缺什么

**已经有的两半，各自健全。**

* **区域**（`docs/299`，已实装）：`&T` / `&mut T` 进类型位置；四条省略规则；
  `&a T` 来源标记；结构体携带区域；函数摘要由检查器自己推；违规报 **E041**。
* **域**（`docs/306`–`docs/315`，已实装）：`capability` / `domain` 块、15 种律
  （`regular`…`reachable`）、值的空间绑定、自动守卫、`domain:for`、树边 `child_of`、
  图边 `couple` / `mutex` / `solid`。

**缺的那一块**：域不知道自己管的是**谁的内存**，借用也不知道自己处在**哪个域**里。
于是两句话今天都说不出来：

1. "这一段代码只在这个借用的寿命内有效"——域块有自己的寿命，借用也有自己的区域，
   两个寿命各说各的；
2. "这个域只有读的权"——权限在 `capability` 那边是空间上的（`disk[0..4]`），
   在借用这边是区域上的，中间没有接线。

## 1. 统一模型：第三章形状轴

域的形状今天有两个来源：**位置**（`disk[lo..hi]`）与**时律**（`epoch(N)`、`consumed(1)`…）。
本文加第三个来源：**区域**。

```rust
domain v : borrow(xs) { … }        // 共享借用域
domain e : borrow_mut(xs) { … }    // 独占借用域
```

三条规则，全部落在静态检查上（不下沉到运行期）：

* **R1 寿命**：域的寿命 = 来源的区域。域不能比它借用的值活得长；域在区域结束后出现
  是 E041。
* **R2 权威 ⊆ 权限**：共享借用域里不能写；独占借用域里别人不能碰；写权限只能来自
  `&mut` 或所有权。
* **R3 逃逸**：域内产生的借用不能比域活得更长（否则来源的区域已经被域"提前结束"）。

区域从哪里来，和 `docs/299` 完全同一套：形参的借用、局部的借用、结构体字段携带的区域、
函数摘要里的出参来源。域只是**给一个区域起名字并把它变成一段代码的准入门槛**。

## 2. 十个域

下面每个词条五件事：**写法 / 它保证什么 / 区域从哪来 / 违规报什么 / 判据**。
十个都只用已有的两套机器（区域 + 域），不引入新运行时。

### 2.1 `view(x)` —— 只读视图域

```rust
domain v : borrow(xs) {
    s = s + xs[i];      // 读：自动 guard
    // xs[i] = 1;       // E041：view 域里不能写 xs
}
```

* **保证**：这一块只读 `xs`；域内借出的引用都是共享引用；域不能比 `xs` 的借用长。
* **区域**：`xs` 的共享借用（`&xs` 或一个 `&T` 形参/字段）。
* **违规**：`view 域里只能读 xs，不能写`（E041 家族，点名 `xs` 与行号）。
* **判据**：正例读通过；负例写必须失败，而把 `view` 换成 `exclusive` 后同一段能编过
  （证明失败来自 `view`，不是别的）。

### 2.2 `exclusive(x)` —— 独占窗域

```rust
domain e : borrow_mut(xs) {
    xs[0] = 1;          // 写：只有这里能写
}
// use xs;              // 块外恢复可用
```

* **保证**：域内独占 `xs`；**域外**对 `xs` 的任何使用/借用都是 E041，直到块结束；
  出块恢复。
* **区域**：`xs` 的独占借用。
* **违规**：`exclusive 域外不能使用 xs（区域还在域里）`。
* **判据**：域外读必须失败；出块后读必须成功；域内嵌套一个同名 `exclusive` 必须失败
  （别名，R2）。

### 2.3 `split(xs, at k)` —— 拆分域

```rust
domain:split (lo, hi) from xs at k {
    lo[0] = 1;
    hi[0] = 2;          // 两侧同时写：区域互斥
}
```

* **保证**：两个子域来自同一个来源、区域互不重叠（`docs/315` 的 `mutex` 边由这里自动
  导出，不手写）；跨两侧的借用是 E041。
* **区域**：`lo = xs[0..k]`、`hi = xs[k..len]`；`k` 是编译期常量时**零运行期代价**，
  是动态值时发一次 `k <= len` 的检查。
* **违规**：`split 的两半重叠` / `下标越界`。
* **判据**：字面量 `k` 时交叉访问失败；动态 `k` 时 `k > len` 运行期报错；两侧并行
  （`couple`）能编译并跑对。

### 2.4 `window(xs, lo, n)` —— 窗口域

```rust
domain w : borrow(xs[lo .. lo + n]) {
    v = xs[lo];         // 域内下标自动减 lo
    // xs[lo + n] = 1;  // E041：越窗
}
```

* **保证**：域内的下标域是 `[lo, lo+n)`；窗口引用不能带出块（R3）。
* **区域**：`xs` 的一个子区域。
* **违规**：`窗口域内下标越窗` / `窗口引用不能离开窗口域`。
* **判据**：静态界越窗失败；`lo+n > len` 运行期报错；窗口引用 `return` 出去必须失败。

### 2.5 `cursor(xs)` —— 游标域

```rust
domain c : cursor(xs) {
    while c.has {
        let x: &u32 = c.next();   // 借用只活一轮
        s = s + *x;
    }
}
```

* **保证**：`next()` 交出的借用**只活到本轮回边**（`docs/299` 的区域在循环回边结束）；
  同时持有两个元素的引用是 E041。
* **区域**：每一轮一个子区域，来源是游标持有的独占借用。
* **违规**：`游标的一轮里不能同时持有两个元素`。
* **判据**：把上一轮的 `x` 存进域外局部 → 失败；只在本轮用 → 通过；与 `domain:for`
  配合时回边推进虚拟钟（`docs/315` §1.2）。

### 2.6 `freeze(x)` —— 冻结域

```rust
domain f : borrow(xs) {            // 来源是独占借用，域内降级为共享
    s = s + xs[0];
}
xs[0] = 9;                          // 出块恢复可变
```

* **保证**：把一个 `&mut` 在域内**降级**成共享；域内写是 E041；出块自动恢复可变。
  这是"只读一段"的最小写法，不用把 `&mut` 传出去再拿回来。
* **区域**：`xs` 的独占借用，域内以共享权使用。
* **违规**：`freeze 域里不能写`。
* **判据**：域内写失败、出块写成功；域内把 `&mut` 交给别的函数失败。

### 2.7 `loan(x)` —— 借出域

```rust
loan buf to other {
    other[0] = 1;
    // buf[0] = 2;      // E041：借出期间不能用 buf
}
buf[0] = 3;             // 块后恢复
```

* **保证**：`x` 在域内**不可用**（编译器把名字挡掉），域外恢复；退出路径（`return`、
  `break`、`?`）上区域同样结束，所以恢复不依赖控制流。
* **区域**：`x` 的独占借用，绑给 `other`。
* **违规**：`loan 期间不能使用 x`。
* **判据**：域内用 `buf` 失败；块后用成功；域内 `return` 后调用方用 `buf` 成功
  （退出路径上的恢复）。

### 2.8 `epoch` —— 借用纪元域

```rust
domain ep : epoch {
    let p: ptr = alloc(64);
    let q: &u64 = p as &u64;
    // return q;        // E041：纪元的借用不能带出
}
```

* **保证**：域内产生的**所有**借用必须在域内结束。跨域返回借用、把借用存进活得更久的
  结构体，都是 E041。它与 L2 的"分配纪元"同名但不同轴：L2 管**回收**，这里管**区域**。
* **区域**：不绑定某个值，而是"本块"的区域；块内所有借用都以它为上限。
* **违规**：`epoch 域里的借用不能带出`。
* **判据**：`return &域内值` 失败；纯域内使用通过；与 `gc_auto_alpha` 的 L2 同时开
  时两者互不干涉（各有各的判据）。

### 2.9 `session(x)` —— 会话域

```rust
domain s : session(conn) {
    give(conn);         // 移交一次
    // give(conn);      // E041：已经移交过
}
// use conn;            // E041：所有权已经走了
```

* **保证**：线性。域内 `x` 的所有权**恰好移交一次**；域尾 `x` 不再可用；重复移交、
  移交后再借都是 E041。
* **区域**：`x` 的所有权（不是借用），区域的结束 = 所有权离开本块。
* **违规**：`session 已经移交过 x` / `x 已经移交，不能再用`。
* **判据**：两次移交失败；域后使用失败；正常移交一次通过；移交后接收方能写。

### 2.10 `seal(buf)` —— 封印域

```rust
domain sl : seal(buf) {
    read(fd, buf, n);   // 交给外部：允许
}
// read(fd, buf, n);    // E041：buf 未封印，不能交给外部
```

* **保证**：把"内存交给外部（系统调用 / `extern fn`）"变成**有边界的许可证**。域内允许
  把 `buf` 交给外部；域外这样做是 E041。同时它把 `docs/210` §2.7 那条"写屏障看不见
  外部写"的缺口在**语法上**标出来：封印域是"这段时间内存可能被外人改"的声明，将来
  屏障与 LMS 可以据此记账。
* **区域**：`buf` 的独占借用。
* **违规**：`封印域外不能把 buf 交给外部`。
* **判据**：域外 `read(fd, buf, n)` 失败、域内通过；域内还允许本地读；与 LMS 第 4 级
  的拒绝判据同时开时，封印域**不**抵消 LMS 的检查（两条规则各判各的）。

## 3. 组合与几何

* **嵌套**：`view` 里套 `window` 合法（子区域落在父区域里）；`exclusive` 里再
  `exclusive` 同一个值 → E041（R2，别名）。
* **树边**：`split` 自动导出 `mutex` 边（`docs/315`），两半可以并行；`exclusive`
  与任何别的借用同一值都是 `mutex` 违例。
* **`domain:for`**：与 `cursor` 配合时，回边结束当轮区域（`docs/299` 的 NLL），
  同时按 `docs/315` §1.2 推进虚拟钟。
* **并行**：只有 `split` 的两半可以 `couple` 并行；其余九个域默认不可并行。

## 4. 与既有机制的分工

| 机制 | 管什么 | 与借用域的交界 |
|---|---|---|
| 区域（`docs/299`） | 借用不能比来源长 | 域给区域**起名字**并把名字变成准入 |
| GC（`docs/210`） | 运行期回收 | 区域是静态证明，回收是运行期，互不替代 |
| L2 纪元 | 循环里什么时候还 | `epoch` 域管借用逃逸，L2 管回收，各自独立 |
| LMS | 访存点上的检查/拒绝/退出 | `seal` 域是第 4/5 级的语法载体 |
| `defer` | 退出路径上的清理 | defer 在区域结束**之前**跑（`docs/299` §3.5） |

## 5. 诊断

全部并入 **E041**（生命周期/区域），消息必须点名**域、值、行号**：

```
E041: view 域里只能读 xs，不能写（视图域 v，行 12）
E041: exclusive 域外不能使用 xs：区域还在域 e 里
E041: split 的两半重叠：xs[0..k] 与 xs[k..len] 在 xs[3] 处
E041: 窗口域内下标越窗：xs[lo + n]（窗口 [lo, lo + n)）
E041: 游标的一轮里不能同时持有两个元素
E041: freeze 域里不能写 xs
E041: loan 期间不能使用 buf
E041: epoch 域里的借用不能带出（行 7）
E041: session 已经移交过 conn
E041: 封印域外不能把 buf 交给外部
```

"生命周期错误"这种不点名的句子仍然不许出现（`docs/299` §5）。

## 6. 判据

每个域**两条**：一条正例（该过的过），一条负例（该拒的拒，且**未实现时它能编过**
—— 否则判据在空转）。第十一条是"域不存在时行为不变"。

| 域 | 正例 | 负例 |
|---|---|---|
| `view` | 域内读，跑出正确值 | 域内写 → E041 |
| `exclusive` | 域内写、域外读 | 域外访问 → E041 |
| `split` | 两半各写各的、并行跑对 | 交叉访问 → E041；动态 `k` 越界 → 运行期 |
| `window` | 窗口内读 | 越窗访问 → E041 |
| `cursor` | 逐元素累加 | 保存上一轮的引用 → E041 |
| `freeze` | 域内读、出块写 | 域内写 → E041 |
| `loan` | 域内用 `other`、块后用 `x` | 域内用 `x` → E041 |
| `epoch` | 全在域内用完 | `return` 域内借用 → E041 |
| `session` | 移交一次、接收方可用 | 两次移交 → E041 |
| `seal` | 域内外部调用 | 域外外部调用 → E041 |
| 十个都不写 | 与今天逐字节相同 | —— |

外加：每个域的示例都进 P8 孪生语料，两个实现逐字节一致。

## 7. 明确不做

* **不做运行时借用计数**（`RefCell` 那种）：与 `docs/299` 的方向相反，而且会把
  编译期错误变回运行期错误；
* **不让域跨函数传递**：域是块的，出了块就没有名字；跨函数的边界仍由函数摘要表达；
* **不引入 `'a`**：`docs/299` 的省略规则不变，域只是给已有区域一个**块内的名字**；
* **不用域替代 `guard`**：显式 `guard` 仍然可用，域管的是"自动 + 区域"。

## 8. 实现成本与分期

| 期 | 内容 | 依赖 | 状态 |
|---|---|---|---|
| 1 | `borrow` / `borrow_mut` 两种形状 + R1/R2/R3 三条检查 + `view` / `exclusive` / `freeze` | `docs/299` 的区域环境 | **参考侧已落**；自举侧下一期 |
| 2 | 形状运算：`split` / `window` / `cursor`（子区域、越窗、回边） | 期 1 + `docs/315` 的 `mutex` 边 | 未开始 |
| 3 | `loan` / `epoch` / `session` / `seal`（退出路径、线性、外部调用表） | 期 1–2 | 未开始 |

期 1 的落地形状：`domain [NAME :] borrow(NAME) { … }` / `borrow_mut(NAME) { … }`，
`DomainBlock` 多两个字段（`borrow_src` / `borrow_mut`），时律固定 `regular` ——
**进 IR 与普通块同形**，所以接受这份程序的两个实现产物逐字节不变（种子不变）。
三条规则落在 `_borrow_domain_errs`：写（赋值 / `store8`…）、再借（`&` / `&mut`）、
`return` 借用、借用期间 `free`、源不可见。

自举侧的检查器是 token 级的：区域环境挂在现有 env 上，域的名字表按块建、按块销毁 ——
这与 `docs/314` 已经落地的域栈是同一套机械，不需要新的 AST。

**判据先红后绿**：每期的负例先在没有该域支持的主干上跑一遍，确认它"能编过"（否则
判据测的不是这条规则）。
