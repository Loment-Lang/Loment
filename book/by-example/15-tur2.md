# Tur 2026.2 syntax

The sugar that Tur 2026.2 adds: `def`, `and` / `not`, `elif`, `for x in xs`, `break` / `continue`,
and `print_num`.

```rust,run
module be_tur2

choose runtime

use "helpers.lomt"

def grade(n: u32) -> u32 {
    if n >= 90 and n <= 100 {
        return 4;
    } elif n >= 75 {
        return 3;
    } elif n >= 60 {
        return 2;
    }
    return 1;
}

fn main() {
    let scores: [u32; 5] = [95, 80, 61, 40, 100];
    let total: u32 = 0;
    for s in scores {
        if s == 40 {
            continue;
        }
        if s == 100 {
            total = total + grade(s);
            break;
        }
        total = total + grade(s);
    }
    print_num(total);
    nl();
}
```
<!-- expect: 13 -->

- `def` is `fn`; `and` / `not` are `&&` / `!`; `elif` is `else if`.
- `for x in xs` accepts a named array or a slice parameter, and `x` is a copy.
- `break` and `continue` act on the innermost loop.
- `print_num` writes an integer in decimal with no newline; it needs `choose runtime`.
