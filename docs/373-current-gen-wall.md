# 373 · 本世代的墙：把「只信产物」推到指令集

> 状态: **激进提案的第二段**（2026-11-20），未实装
> 上游: `docs/358`（只信产物）· `docs/253` §2E/§5.5（元数据三出口与地板）·
> `docs/320` §1.2/§8（CHERI / MTE 的判断）· `docs/356`（fault ABI）·
> `docs/275`（clang 版本与逐字节比对）· `docs/229` §3.2（默认产物逐字节相同）
> 基准: `origin/main` `a460b90e`
> 一句话: **`docs/358` 的强声明需要六个硬件原语；本世代的 x86-64 / ARM64 一个完整版都没有。
> 墙的位置可以精确到指令，能跑的是一个被削弱的子集。**

---

## 0. 先把"几乎不可能"说准

这句话有三层意思，混在一起会说不清：

| 层 | 含义 | 今天成立吗 |
|---|---|---|
| **跑不动** | 算法太慢，工程上不可接受 | 部分是（影子内存、逐访问检查） |
| **没有 ISA 支持** | 需要的原语在指令集里不存在 | **本文的主结论** |
| **硬件不在证明里** | 软件验完了，CPU 本身不可核 | **最深的一层，且无解** |

下面是 `docs/358` 的强声明拆出来的六个原语。一个都没有完整版。

| # | 原语 | 用来兑现 `docs/358` 的哪条 | x86-64 今天 | ARM64 今天 | 谁有 |
|---|---|---|---|---|---|
| **P1** | **指令级标记**：硬件知道哪条指令是访存 | 完备扫描（A 链） | 无 | 无 | 无主流 |
| **P2** | **能力字**：指针里带基址/上界/类型 | 完备边界（W2） | 无 | 无 | CHERI / Morello |
| **P3** | **非概率对象代**：free 后旧引用必失效 | 悬垂（W3） | 无 | MTE 是概率性 | CHERI + 撤销服务 |
| **P4** | **语言级故障**：同步、带站点、可恢复 | fault ABI（W4） | 只有 `#PF` + CR2 | 只有同步异常 | 无主流 |
| **P5** | **精确 checkpoint**：任意点快照 | fork / 迁移（W5） | 无（TSX 已死） | 无 | 无主流 |
| **P6** | **可核的 ISA 契约**：硅片本身可验 | 信任基座的顶 | 无 | 无 | RISC-V 有形式模型，硅片未验 |

## 1. 六堵墙

### W1 · 完备扫描撞上"指令级标记"

`docs/358` 的 A 链已经把完备性从源码换到产物。换完之后还有一步：
**验证器怎么知道哪条指令是访存？**

- 由编译器标记 ⇒ 恶意编译器可以不标 ⇒ A 链原样杀回来。
- 由验证器自己解码 ⇒ x86 是变长指令，需要一个完整反汇编器。

量化这一堵墙：

| 路线 | 代价 | 问题 |
|---|---|---|
| x86 通用反汇编 | 一个可用解码器是数万行；正确性本身要证 | `docs/358` C2 的 `max_bytes` 预算直接爆 |
| 固定长度 RISC 子集 | 解码便宜 | 本世代主流出货是 x86-64 / ARM64 |
| 编译器标记 + 抽样复核 | 便宜 | 抽样证明不了"没有未标记的访存" |

**本世代没有 ISA 提供"这条指令是 load/store"的硬件标志。** P1 是空的。
这就是 `docs/358` 第一版演示把 LVM 字节码当 claim 载体的原因：
LVM 的 load/store 是固定操作码，解码器可以很小；x86 上做不到同样的小。

### W2 · 完备边界撞上"指针内元数据"

今天的指针是 64 位裸地址，没有界。要让每次访问知道界，元数据只有三个位置
（`docs/253` §2E 已经把这张表写死）：

| 位置 | 代表 | 本世代代价 |
|---|---|---|
| **进指针** | 胖指针 / CHERI capability | 指针翻倍，ABI 全变；CHERI 不是主流出货 |
| **出带外** | 影子内存 / ASan | 影子 1:8，加红区与隔离；每次访问多一次 load |
| **进硬件** | MTE | 4 位 tag、16 字节粒度；**概率性** |

三条都真的贵。`docs/253` §2E 的结论是"完备 + 零成本 + 不改语言"是闭合死链；
这里再加一句：**本世代没有一条能在商品 x86-64 上做到"非概率 + 无扫描 + 每次访问检查"**
（`docs/320` §8 的 I3）。

### W3 · 对象代撞上"free 后失效"

`docs/358` 的 `checked` 站点要求一条 fault 边；悬垂检查需要对象代。
代住在哪：

- **对象头**：每次 `free` 写一次；无界堆对象可行，但入侵 ABI 与分配器；
- **槽表**：只对有界槽成立（`docs/320` §5.3 的 S1 就是这个）；
- **指针**：胖指针，回到 W2。

MTE 在 `free` 时换 tag，但 4 位只有 16 个值，可猜、可碰撞；`docs/320` §1.2 ⑧
已经写死它是**检测**，不是**保证**。本世代没有非概率的硬件对象代。

### W4 · 语言级故障撞上"信号"

`docs/358` 要求 `F01..F09` 带站点、退出码、可被验证器核对（`docs/356` §5.2/§5.3）。

今天的 trap 是 SIGSEGV / SIGILL：异步、不可恢复、没有站点。x86 的 `#PF`
有 CR2（故障地址），但没有"这是哪个语言站点"；要回答后者，需要一张从地址到站点的表，
而表是运行期状态 —— 与 `no_runtime` 直接冲突（`docs/358` §1D）。

可行的弱形态已经写在 `docs/356`：固定的 syscall-only stub，退出码 `100 + kind`，
站点号由编译器写死在调用点。**这已经是本世代能拿到的最好形态**：
故障是**语言事件**（带站点），恢复仍然做不到（`docs/356` §11 第 5 条）。

### W5 · 精确快照撞上"架构可见状态"

PANGU 的 fork / freeze / migrate 要求抓到运行中的全部状态。
今天的 ISA 不暴露 cache、TLB、分支预测器、in-flight 内存操作；这些状态不属于架构可见面。

- **CRIU** 在 **syscall 边界**工作，用 ptrace 停住进程；mid-instruction 快照做不到。
- **事务内存**（TSX）本来是最近的一条路，已经因 errata 在多数芯片上关闭，部分型号移除。
- **虚拟机快照**能抓架构状态（寄存器、内存、设备），抓不到微架构状态；而且它抓的是**整机**。

⇒ 本世代能主张的只有 **syscall 边界快照**。这与 `docs/358` §9 第 5 条一致：
任意运行期状态的 fork 不主张。

### W6 · 硬件本身不在证明里（最深的一堵）

即使 P1–P5 全部到位，`docs/358` 的验证器验的仍然是**软件**。
执行它的那颗 CPU 是一个假设：

- x86-64 / ARM64 的**出货硅片**没有形式化的、可核的契约；有 errata、有勘误表、有微码更新；
- RISC-V 有 Sail 形式模型，但模型与硅片之间仍有一道不可核的缝；
- CHERI 把检查搬进硬件，但硬件实现本身仍可能错（CHERI 的验证工作正是为此）。

**这一堵墙与性能无关，与指令无关。** 它是 Thompson 地板在硬件上的版本：
你可以给产物盖章，给不出"这颗 CPU 实现了它的 ISA"的证明。

本世代没有 P6。所以 `docs/358` 的最终一句话只能是：

> **在"这颗 CPU 正确实现了它的 ISA"这条公理下，产物 + 封印 + 验证器 + 种子哈希是完整的信任基座。**

把公理写出来，比假装它不存在有用。

## 2. 墙有多高：一张诚实的表

数字凡是没在本仓测过的，标 **未测**。不拿直觉定价（`docs/356` §10 判据 7 同一纪律）。

| 替代品 | 量级 | 性质 | 墙高 |
|---|---|---|---|
| 影子内存（ASan 形状） | 影子 1:8，加红区与隔离 | **检测**，不是保证（`docs/253` §1.2、`docs/320` §1.2 ②） | 中：内存与一次额外 load |
| 胖指针 | 指针 2× 宽 | 完备边界 | 高：ABI 与结构体膨胀 |
| 逐访问边界检查 | 每访问 1–2 条指令 | 完备边界（常量界更便宜） | 未测；会阻碍向量化 |
| MTE | 4 位 / 16 字节 | 概率性 | 中：不满足"非概率" |
| CHERI | 128 位能力 | 空间强，时间要撤销服务 | 高：要新芯片 |
| x86 通用反汇编 | 数万行 | 解码正确性 | 高：预算爆 |
| CRIU | syscall 边界 | 精确到边界 | 中：mid-instruction 不行 |
| 硬件 errata | — | 不可核 | **无解（P6 空）** |

三行要特别说清：

1. **ASan 与 MTE 都是检测。** 检测的价值是"抓到了"，保证的价值是"不会发生"。
   `docs/358` 的声明要的是后者。
2. **边界检查的成本取决于界是不是常量。** Loment 的堆是定长 arena，栈帧自己排
   （`docs/253` §11.2），所以大量界是常量 —— 这是 `docs/358` 在本世代能站住的少数原因之一。
3. **反汇编器的成本是验证器预算的生死线。** 这也解释了为什么第一版演示钉 LVM。

## 3. 六个原语，谁有，什么时候有

| 原语 | 最近的一条路 | 成熟度 | 本世代可得 |
|---|---|---|---|
| P1 指令标记 | 定长 ISA 子集 / LVM 字节码 | 可用，但只覆盖自家字节码 | **部分** |
| P2 能力字 | CHERI / Morello | 研究芯片与少量产品 | 否 |
| P3 非概率对象代 | CHERI + 撤销服务 | 研究 | 否 |
| P4 语言级 fault | `docs/356` 的 syscall stub | 本仓可做 | **弱形态** |
| P5 精确 checkpoint | CRIU（syscall 边界） | 生产可用 | **边界形态** |
| P6 可核 ISA | Sail / 形式化 ISA | 模型有，硅片无 | 否 |

"部分"与"弱形态"是本文的关键词：本世代拿得到的是**五个半**，不是零，也不是完整。

## 4. 本世代能跑的那个子集

把 `docs/358` 的强声明逐条削到墙上，得到一张"今天可交付"的表：

| `docs/358` 的声明 | 本世代形态 | 放弃了什么 | 判据 |
|---|---|---|---|
| 完备扫描（A 链） | **LVM 字节码**上完备；原生 ELF 只到标记子集 | x86 上的完备 | C1 / C3 |
| 完备边界（W2） | 常量界证明（LMS g1）+ 动态界检查 | 无界的全量元数据 | C3 / C4 |
| 悬垂（W3） | **只有有界槽**的对象代（`docs/320` S1） | 无界堆对象的代 | `docs/320` §12 的 S1 判据 |
| fault ABI（W4） | syscall-only stub，退出码 `100+kind` | 可恢复 | C9 |
| fork / 迁移（W5） | **syscall 边界**快照 | mid-instruction | C7 |
| 硬件（W6） | 写进地板的公理 | 硅片可核 | 无判据，只能声明 |

**这一版比 `docs/358` 弱，但每一条都可核。**
`docs/358` 的 C1–C10 里，本世代能过的是 C1、C3（LVM 档）、C4、C5、C6、C7、C9、C10；
C2 取决于验证器能否压进预算；C8 取决于第二个实现。
悬垂只到有界槽，那一条不在 C1–C10 里，由 `docs/320` §12 的 S1 判据管。

## 5. 为什么这仍然是激进的

**因为结论本身就是激进的：`docs/358` 的强声明在本世代几乎不可能。**
它需要六个原语，本世代有零个完整、两个部分、一个弱形态。

但"几乎不可能"不等于"什么都不做"：

- 削弱的子集今天就能做，而且没有别人做（`docs/357` §6 的前史表仍然成立）；
- 墙的位置可以精确到指令，这比"等下一代硬件"有用得多；
- **下一代硬件只解除 W2/W3，不解除 W1/W5/W6。**
  P1 要 ISA 改，P5 要事务内存或硬件 checkpoint，P6 要可核的硅片。
  所以"等 CHERI 来了就都好了"这句话是错的 —— 它只买走两堵墙。

一句话：

> **本世代的正确姿势是：把能核的那一半做出来，把核不了的那一半写成公理，并给每一条公理标价。**

## 6. 判据（每条先红）

| # | 判据 | 先红的方式 |
|---|---|---|
| **H1** | 影子内存版的内存增量与本仓的堆上限（64 KiB arena）对账 | 今天没有影子版 ⇒ 红 |
| **H2** | 固定迭代下边界检查的指令数与稳定计时；记录中位数与 IR 指令数 | 今天没有检查 ⇒ 红；**不许用墙钟比值当门禁**（`docs/226` 的教训） |
| **H3** | 反汇编器/解码器的行数与字节数 ≤ 验证器预算 | 今天没有解码器 ⇒ 红 |
| **H4** | MTE / CHERI 在本机不可用 ⇒ 跳过，并记 `skipped` | 写成红就是环境假红（`docs/345` §4.3 的 skip 纪律） |
| **H5** | 削弱子集逐条对 `docs/358` 的 C1–C10 打勾 | 少一条 ⇒ 声明有洞 |
| **H6** | ISA 正确性作为公理进封印的 `floor` | 没写 ⇒ 假装它不存在 |

H4 的写法要照 `docs/344` §4.3：跳过必须有原因，`skipped` 不计入 `proved`。
H6 没有判据可跑，只能检查**封印里有没有这一行**。

## 7. 我不主张

1. **不主张上表的数字是精确的。** 没在本仓测过的都标了"未测"；量级给的是文献常识。
2. **不主张 CHERI 是唯一出路。** 它是已知最完整的一条；MTE + 对象代、硬件 tag、
   定长 ISA 都能各解一部分。
3. **不主张本世代做不了安全。** 本世代能做的是**更弱的声明**，弱声明一样可核。
4. **不主张下一代硬件解决全部。** 它只解除 W2/W3；W1/W5/W6 要 ISA 与硅片的改动。
5. **不主张软件能验证硬件。** W6 是本世的墙，写进地板是唯一诚实的处理。
6. **不主张快照在虚拟机层做不到。** 做到的是整机、架构状态；微架构状态仍然抓不到。
7. **不主张"墙"是永久的。** 它是本世代的；墙的高度随 ISA 变。
