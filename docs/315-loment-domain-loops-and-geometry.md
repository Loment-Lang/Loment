# 315 · 域循环与域几何：`domain:for`、横/竖树、平/立体图

> 状态: **域循环、域嵌套、树边 `child_of`、图边 `couple` / `mutex` / 体 `solid`、
> **撤销级联 `revoke`（`docs/306` C2）**、域几何报告全部实装（两个实现逐字节一致）；
> 未实装的是 `→` 委托、`≺` 时序、`×` 排他与扩展域**
> 上游: `docs/306`（代数）· `docs/307`（语境类）· `docs/308`（嵌套与环）· `docs/314`（域块）
> 一句话: **域不只围住一段代码，它能被遍历；遍历的骨架就是域的树与图。**

---

## 0. 用户说的两个词，先拆开

| 词 | 本文叫法 | 是什么 | 今天的状态 |
|---|---|---|---|
| 域循环 | **驱动环** | `domain:for`：沿域的形状走一遍；每条回边推进虚拟钟 | **已实装** |
| 域嵌套 | **嵌套链** | `domain` 块套 `domain` 块；守卫逐层判、只扣叶子 | 已实装（`docs/314` §3.1） |
| 域树 | **横 / 竖** | 由嵌套、分支、并行、位置四种边导出的结构 | 已实装（§4；C1 + C2） |
| 域图 | **平面 / 立体** | 域与域之间的 `→` / `⇄` 边；立体多一轴与跨层边 | `⇄` / `⊥` / 体已实装；`→` 设计 |

树与图**不是**新的运行时机制：它们是把已有的边（嵌套、分支、循环、耦合）**读出来**的
形状。所以本文先把它们定义清楚，再谈什么时候进语言。

## 1. `domain:for`：表面与语义

### 1.1 写法

```rust
domain buf : disk[0..7] consumed(1) {
    domain:for i {
        a[i] = a[i] + 1;      // 循环头已经守卫过 i，这里不再重复
    }
}

domain:for i in buf step 2 {   // 点名一个域（可以离得很远），跳跃式遍历
    ...
}
```

- `domain:for i` —— 遍历**最内层** `domain` 块的那个域。
- `domain:for i in NAME` —— 遍历作用域里名为 `NAME` 的域。
- `step N` —— 位置序列 `lo, lo+N, lo+2N, …`（横向树的**跳跃并行**那一半）；
  `step -N` 反向，从 `hi` 走到 `lo`。
- `domain:for i, j in A, B` —— **横向并行**：一轮里两个域各判一次，跨度必须相同。
- `domain` 与 `for` 之间**没有空格**也可以：`domain:for` 是一个整体记号；
  `domain` 仍是上下文关键字，`sock_new(domain: u64, …)` 照旧编得过。

### 1.2 语义

反糖成一条普通的循环：

```
let i: u32 = lo;
while i <= hi {
    guard D(i);        // 循环头**一次**
    …body…
    i = i + N;
}                      // 回边 = tick
```

四条可判的性质：

1. **头一次守卫**：一次 `guard` 落在循环头，一轮一次；**体内同位置的访问不再挂
   自动守卫**（`While.proven`）。有状态的域否则会被扣两次。
2. **回边即 tick**：单元用了虚拟钟（有任何 `guard` / `tick;` / `domain`）时，每条
   循环回边推进一次钟 —— `while`、`for`、`continue` 都算。没用域的程序**一个字节不发**。
3. **逃生舱**：`choose domain_clock_explicit` 关掉自动 tick，回到"只有 `tick;` 推钟"
   的旧语义。它是**编译器定义的开关**（与 LMS 七个细开关同一条），不必写 `set choose`。
4. **只遍历可顺序化的域**：无界形状（`[()..hi]` / `[lo..()]`）、`danger` 极性、
   以及要第二个实参的 `subject` / `witnessed` / `flow` —— 五类都在编译期拒。

### 1.3 为什么变量是 `u32`

域的判决口 `@__loment_guard2` 收 `i64`，而守卫发射走的是 `zext i32 … to i64`
（所有显式 `guard` 同一条路）。循环变量取 `u64` 会发出一条 `zext i32 %i64值` ——
非法 IR。所以反糖写 `u32`；上限是域的形状，而形状本来就来自字面量。

### 1.4 树的声明：`child_of`

```rust
domain outer : disk[0..7] {
    domain leaf : disk[0..3] child_of outer { a[0] = 1; }
}
```

`child_of` 是显式的**竖向树边**：父域必须正在包围它、同一空间、子 ⊆ 父（C1）。
不加它时父子关系只由括号隐含；加上之后这条边会进几何报告，而且跨空间 / 越界 / 点名
一个不在外层的父域都是编译错误。

### 1.5 图边：`couple` 与 `mutex`

```rust
capability ring    : disk[0..15] adaptive
capability partner : disk[0..15]
capability other   : mem[16..19]

fn pump(a: [u32; 16] in disk) -> u32 {
    couple ring, partner;    // ⇄ 联动：同一位置上一起续期
    mutex  ring, other;      // ⊥ 互斥：两个形状必须可证不相交
    ...
}
```

- **`couple A, B, …`**：把它们并成一个续期单位。对任一成员的守卫会**静默地**再确认
  其余成员在同一位置上仍然有效（`kind | 128`，不记账、不转移）；`quality` 写到任一
  adaptive 成员上时整组一起写。若干成一片（连通分量），那就是一个**原子续期单位**
  （`docs/308` §2.5 的 SCC）。耦合的两个域必须至少共享一个位置。
- **`mutex A, B`**：编译期承诺 —— 两个有限、非 danger 的形状不能相交；运行期一条指令
  都不发。

两条语句都是**上下文关键字**：`couple` / `mutex` 后面紧跟名字与 `,` 或 `;` 才是声明。

### 1.5.1 体：`solid`

```rust
solid body : ring, partner;   // 一个**有名字**的联动组 = 立体图的"体"
guard body(3);                // 判根本身，其余成员静默地一起判
quality body = 128;           // 质量写到整组（adaptive 成员）
```

`solid` 是 `couple` + 一个名字：

- 名字解析到**根成员**（第一个）。`guard body(x)` 于是等于"判根 + 静默判其余成员"
  —— 剩下的由联动已经做了；
- 体的审计落在根成员那一格：一个体只多一条审计，不额外占槽；
- 三条轴由成员给出：位置（形状）、时间（律 / 续期）、质量（adaptive 成员）；
- 成员可以含**祖先与后代**（跨层边），也允许块域与能力混搭；
- 联动图**按函数**求分量：另一个函数里的块域不会被算进伙伴（它的状态在这里不存在）。

### 1.6 与嵌套的关系

`domain:for` 是**透明的一层**：它不占审计槽，也不切断外面的域。循环体里的
`guard half(i)` 照样看得见外层 `domain half { … }`（`chk_dom_has` 的反向扫描在
`domain:for` 处继续往外走）。

### 1.7 撤销：`revoke`（`docs/306` C2）

```rust
capability ring : disk[0..15] revocable

fn pump(a: [u32; 16] in disk) -> u32 {
    guard ring(3);      // 放行
    revoke ring;        // 从此这个实例整体拒绝
    guard ring(4);      // trap
    return a[0];
}

domain dma : disk[0..7] revocable {
    revoke dma(5);      // 只撤位置 5；其余位置照旧
}
```

- **`revoke NAME;`** 撤整个实例；**`revoke NAME(x);`** 只撤一个位置（`x & 63` 记在
  64 位位图里，与 `consumed` 的 `used[64]` 同一条口径）。
- 只能撤声明了 **`revocable`** 的域。写到不可撤的域上是编译错误；自举侧同样拒
  （`cg_fail`），不会静默写到共享零格上。
- **级联是链的性质，不是传播指令**：守卫本来就走整条竖向链，链上每一层各自带
  自己的撤销位对。撤了父，子域那条链上的父判决当场就拒 —— 于是"撤父 ⇒ 整棵子树
  拒绝"成立，而普通程序一个字节不多发。
- **墓碑**：顶层能力的撤销位在全局表 `@__loment_rev` 里，置起后同一份产物里不再
  复位。语言里没有运行期句柄，因此"已撤销的 id 不复用"落地为"同一实例的撤销单向
  且不可逆，而新实例是新节点"。
- **块 = 实例**：块域的撤销位是它自己那帧的一对 `alloca [2 x i64]`，块入口清零 ——
  下一轮循环 / 下一层递归是新实例，本来就没被撤过。
- **体的名字撤全组成员**（`docs/315` §5.2：体要么整体续期、要么整体拒绝）：块的按
  作用域由外到内、能力的按声明序 —— 两个实现同一个顺序。

运行期形状（`@__loment_revoke(ptr %rv, i64 %idx, i64 %all)`）：`all != 0` 写整实例
位，否则把 `1 << (idx & 63)` 或进位图；`@__loment_guard2` 每次判决先读这两格，
任一置起就直接走 trap。

实测（ELF 经 WSL，`/tmp` 原生路径）：

| 探针 | 结果 |
|---|---|
| 撤顶层能力后再判它 | `SIGILL`（Python 侧 `returncode = -4`） |
| 不撤、只判 | `0` |
| 撤父 → 判孙（`child_of` 链） | `SIGILL` —— 级联 |
| 循环第 1 轮撤、第 2 轮判（新实例） | `0` —— 实例复位 |
| 只撤位置 1，再判 2 放行、判 1 | `SIGILL` —— 位置位图 |

## 3. 域嵌套：今天已经成立的四条

1. **合取**：同空间链 `d₀ ⊃ … ⊃ dₙ` 逐层判成员；任一为假即 trap。
2. **只扣叶子**：祖先带 silent 位（`kind | 128`），只有被点名的那一层记账 / 转移。
3. **包含（C1）**：内层形状必须落在（或等于）外层；跨空间嵌套不构成链，各判各的。
4. **寿命**：块 = 实例；时间律读同一个全局钟，祖先到期时子域的判决当场变成拒绝。
   有状态律的状态在**当前栈帧**分配，循环每轮、递归每层各一份。

`docs/308` §1.4 的极性四格由"链上每层各判一次"自然得到：
`allow∩allow`、`allow∖deny`、`deny∖allow`、`deny∪deny`。反例照旧：
`deny` 父 + `allow` 子**做不出白岛**，那是图上的减法边，不是嵌套。

## 4. 域树：横与竖

用户裁定的三条轴**同时成立**，所以"横/竖"不是一个分类，而是两个方向：

### 4.1 竖向树（沿时间与包含）

| 树 | 边是什么 | 读法 |
|---|---|---|
| **决定树** | 嵌套链 `parent → child` | 守卫时**谁先判**；祖先先、叶子后 |
| **推导树** | 子域的形状 / 时律由父域**导出** | `child ⊆ parent`（C1），时律续期沿链截断（C1t） |
| **竖向并行树** | 同一链上**并列**的子实例 | 同一 tick 一起续期；**不许跳位**（位置必须对齐） |
| **撤销树** | 同一条链上的 `revoke` | 撤父 ⇒ 整棵子树拒绝（C2，§1.7）；块实例随块复位，顶层能力是墓碑 |

竖向的关键字是**顺序**：代、续期、判定次序、撤销的级联。`domain` 块的嵌套直接给出
这张树，`domain:for` 的嵌套（循环套循环）给出竖向并行。

### 4.2 横向树（沿位置与分支）

| 树 | 边是什么 | 读法 |
|---|---|---|
| **推导树（分支）** | `if` / `match` 的每一支 | 每支各是一棵推导树；域约束按支合成 |
| **横向并行树** | 同层兄弟域 / `domain:for` 的并行位置 | 同一轮里并排访问；**允许跳位** |
| **跳跃边** | `step N` | 位置序列 `lo, lo+N, …`；跳跃只属于横向 |

横向的关键字是**位置**：第几个、跳不跳、与谁并排。

### 4.3 两条轴怎么合成

一个域块实例的坐标是 `(空间, 时间, 位置)`：

- 竖向决定它的**寿命**（哪一代、哪一层）；
- 横向决定它的**足迹**（哪几个位置、跳不跳、和谁同轮）。

`domain:for` 把横向的位置轴变成可写的东西；回边 tick 把竖向的时间轴变成可写的东西。
两者各自实装，合成才完整。

## 5. 域图：平面与立体

### 5.1 平面图

平面图的坐标是 **空间 × 时间**：

- 顶点 = 域实例；
- 边 `→` = 流向 / 委托（同层，单向）；
- 边 `⇄` = 联动（续期同步，可以成环；SCC = 一个原子续期单位，`docs/308` §2.5）。

今天能画出来的平面图：嵌套（竖向）、`guard` / `discharge`（义务）、联动 `⇄`
（`couple` / `solid`）、互斥 `⊥`（`mutex`）；撤销（§1.7）不是一个边，而是报告里的
一条 `revokes` 记录（撤了哪些顶点、带不带位置）。`→` 委托仍是 `docs/306` §6 的设计。

### 5.2 立体图

立体图比平面图多三条东西（用户裁的 1+2+3）：

1. **第三轴**：能力等级 / `quality`。`adaptive` 域的宽度由质量缩放，于是同一个位置在
   不同质量下是两个不同的顶点 —— 平面图把它压扁了。
2. **跨层边**：边可以穿过嵌套层（父域直接连到某个孙域），平面图只画同层。
3. **耦合环**：`⇄` 的强连通分量是立体图里的一个"体"，同 tick 原子换实例。

立体图的"体"（solid）是**一个 SCC 在三条轴上的一次整体**：位置集合 × 时间区间 ×
质量档。它极其先进的地方在于：**它把"原子"从时间一个方向扩展成三个方向** ——
一个体要么整体续期、要么整体拒绝，不会出现"位置换了、质量没换"的中间态。

这一版实装了体（`solid`，§1.5.1）与它的**拒绝**那一半（撤销，§1.7）：一个体可以
整体续期（`guard` 判根、联动判其余），也可以整体拒绝（`revoke 体名`）。还差的是
"体作为一等值"（把体传参 / 存进结构体），以及 `→` 委托边。

## 6. 判据（今天在树里的）

| 判据 | 喂什么 | 期望 |
|---|---|---|
| 头一次守卫 | `domain:for` 体里访问同位置 | IR 里只有**一条** `__loment_guard2` |
| 回边 tick | 同一个循环 | IR 里有 `call void @__loment_tick()` |
| 显式档 | `choose domain_clock_explicit` | 没有 `__loment_tick` 调用 |
| 步长 | `step 2` | 更新步是 `add i32 …, 2` |
| 透明嵌套 | 循环体里 `guard half(i)` | 编译通过（外层名可见） |
| 五类拒绝 | 无界 / danger / subject / witnessed / flow / 没有域可点 | 编译期报 E004 |
| 双子 | 同一份源 | 两套实现 IR / Potato 逐字节一致 |
| 撤销 | 顶层能力 / 块域 / 体名 / 位置 | `@__loment_revoke` 的形状与目标数 |
| 级联 | 撤父 + 判子 | 链上父那一层带父的撤销位对 |
| 拒绝 | 撤不可撤的域 / 未声明名 / 体里有不可撤成员 | 解析期报错 |
| 几何 | `revokes` 列表 + `revocable` 标记 | 目标集合与声明一致 |
| 运行 | epoch 域 + 8 次迭代 | 第 3 轮 trap（`now = 3`）；显式档全过 |

运行那些是**实测过的**（ELF 经 WSL）：epoch 那两条是 `rc=132`（SIGILL）与 `rc=7`；
撤销的五格见 §1.7 的表。

## 7. 诚实边界

- **树的声明只有 `child_of`**：兄弟边由作用域隐含，没有 `sibling NAME` 的写法；
  图边只有 `⇄`（`couple`）与 `⊥`（`mutex`），`→` 委托、`≺` 时序、`×` 排他仍是设计。
- **`couple` 的组件按名字认**：同一函数里同名但不同的两个域会被算成一片（罕见）。
  真正的修法是给耦合关系配一张**按声明点**的表，那是下一步。跨函数已经不会串了
  （组件按函数求）。
- **自举检查器只"收下" `child_of` / `couple` / `mutex` / `solid`，不重复那几条语义校验**：
  名字是否存在、形状是否相交 / 越界，今天只有参考实现会拒。孪生判据覆盖的是
  **IR 与产物**，不是诊断。补自举侧的同一组校验是下一个 PR 的事 —— 在那之前，
  发行版里的编译器对这类**写错**的声明是静默接受。`revoke` 是这一组的例外：目标
  不可撤 / 名字不存在，自举侧会在发射期 `cg_fail`（响亮地拒），只是错误码比参考
  实现的诊断粗。
- **撤销只沿树边级联**：撤一个成员不会自动撤掉它 `⇄` 联动组里的伙伴（体名是唯一
  的例外 —— 体本来就声明成"整体拒绝"）。要整体撤就撤体名，或逐个撤。
- **`discharge` 不看撤销位**：结清义务只是清一条记录，不放行任何访问，所以撤销后
  结清仍然成功。这是有意的：拒绝只发生在**判决点**。
- **撤销位是 64 位位图**：形状宽于 64 的域，位置按 `idx & 63` 折叠 —— 与
  `consumed` 的 `used[64]` 同一条口径。
- **横向并行**今天只有 `step`（跳跃）与嵌套循环（竖向并行）；"同轮并排访问两个域"
  还没有专门写法 —— 两条顺序访问的语义已经对，但读不出"并行"。
- **立体图的第三轴**只有 `adaptive` 一条腿；`quality` 是语句，不是图的边。体是
  一套命名与判决，不是值 —— 不能 `let b = body;` 传参。
- **回边 tick 是整单元的**：一个单元里只要有一个域，所有循环都推钟。这是保守的
  正确做法；更细的按函数门会与"时钟是全局的"冲突。
- **`domain:for` 不检查空区间**：`lo > hi` 时它只是不跑。要报的话得在编译期判
  `lo ≤ hi`（形状本来就该判），那是下一个小的改动。
- **Rust 后端不做回边 tick**：`emit_rust` 是自检 / `loment.py test` 的路径，不是
  交付产物；显式 `tick;` 它照发，自动 tick 没有镜像。交付路径（IR → ELF/PE）两条
  实现都做。

## 8. 实装清单（这一版落了什么）

- `domain:for`（含 `in NAME`、`step N`、`step -N`、`i, j in A, B` 并行）—— 两个实现；
- 回边 tick（`while` / `for` / `continue`）+ `domain_clock_explicit` 逃生舱 —— 两个实现；
- 循环体内的守卫抑制（已证位置）—— 两个实现；
- 审计表只数块（`domain:for` 不占槽）—— 两个实现；
- `child_of`（显式树边）、`couple`（联动：守卫的 silent 伙伴判决 + 质量整组写）、
  `mutex`（编译期互斥）—— 两个实现；
- **体 `solid`**（`docs/315` §1.5.1）：couple + 名字；`guard 名(x)` 判根、其余静默，
  `quality 名 = q` 写整组；几何报告里成一条 `solids`；联动分量按函数求；
- 显式 `guard leaf(x)` 走整条链（祖先 silent）—— 两个实现；
- **撤销 `revoke`**（`docs/315` §1.7，= `docs/306` §6.1 的 C2）：整实例 / 按位置、
  沿树边级联、块实例随块复位、体名撤全组、不可撤的域编译期拒 —— 两个实现；
- 联动伙伴只算**作用域里还活着**的那些：块域出块之后，它的伙伴判决不再发（否则那条
  守卫会引用一个本帧已经没有的实例，状态指针退回占位）；参考实现与自举侧现在同一条；
- 判据 12 条（见 §6），其中运行那些是实测；
- **域几何的报告**：`tools/loment_geometry.py` 从 AST 导出竖链（`contains`）、
  兄弟（`sibling`）、先后（`flow`）、守卫（`guard`）、立体图的跨层边（`cross`）
  与 `domain:for` 的位置轴（`step` / `positions`）；输出是确定性的 JSON。
  判据在 `lomentc_test::test_domain_geometry_reads_trees_and_graphs`；
- 种子 / genesis / 地板按流程重算。
