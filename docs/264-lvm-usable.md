# 264 · 「第一个可使用的 LVM」——**它现在成立，以及它不意味着什么**

> 状态: **规范**（2026-10-18，issue #355）· 上游: `docs/231` §2（渠道闸）· `docs/232` §4.6
> （"箱子还是空的"）· `docs/259` / `docs/261`（引擎）· `docs/262`（失败面）
> 一句话: **闸早就开了，但开的时候包里没有可调的东西。** 这一页补的是**宾语**，
> 并且把"开了不等于产物变了"写在最前面。

⚠ **时间线要先说清楚**（否则这一页会读成"我今天开的闸"）：闸是 **2026-10-17 由用户裁决
放开**的（"LVM 完成一大半"），两套 checker 的拒绝与 `loment_channel_test` 判据 D 的期望
都在那一次里改完了。**但那次放开留下了一个空洞**，`lomentc.py` 自己的注释就写着它：
"发行包里**没有它**（解释器），产物也不走字节码"。⇒ **`choose vm` 合法了，而包里没有任何
东西可以调它。** 这一页补的是那一半。

---

## 1. 用户那句话，和它原来的样子

`docs/231` §2 记着 2026-10-11 的原话：

> 「不要在发行版 Loment 里被调用，所有调用 VM 的都是非法的，只能 dev 可以被调用，
> **直到第一个可使用的 LVM 诞生**。」

于是 `choose vm` 在发行版里是**编译错误**，判据 `loment_channel_test` 判据 D 拿一个真建的
发行版驱动器去证它。**"可使用的 LVM"从来不是一个形容词清单** —— 这正是这一页要把它变成
三条可证伪的话的原因。

## 2. 三条，逐条对着判据

| # | 条件 | 判据 |
|---|---|---|
| **A** | **语料全绿**：9 份语料，原生产物与 VM **stdout + 退出码逐字节相同** | `lvm_test`（4/4，孪生 9/9）· `lvm_twin_test`（3/3，参考 vs 自举镜像，含**剖面**逐字节） |
| **B** | **T3 唯一的硬判据成立**：去优化之后结果仍然对 | `lvm_t3_test`（3/3）：夹具**恰好**去优化一次、答案 rc=18、副作用只发生一次、反例零去优化 |
| **C** | **错的时候有界**：不认识的系统调用 / 不支持的指令 / 越界 / 栈溢出 / 挂死，五种都**点名失败** | `lvm_stability_test`（3/3）· 上限表在 `docs/262` |

**三条都成立**（2026-10-18 实测）。所以按用户自己给的条件，闸该开 —— 而它在 10-17 已经开了
（见开头那段时间线）。这一页的作用是把"该开"的**判据**写下来，好让下一次有人问
"凭什么开"时有一张能逐条核的表，而不是一句裁决。

## 3. ⚠ 开闸**不**意味着什么（这一节比上一节重要）

**发行版里 `choose vm` 仍然不改变产物。** `docs/232` §4.6 那句"箱子还是空的"**今天仍然成立**：
同一份源，写了 `choose vm` 与不写，产物**逐字节相同**。

那么开的是什么？**开的是"有东西可调"这件事**：

* `loment-lvm` 从 `loment_dist.TOOLS` 随包发 —— **包里真有一个能跑 `.ll` 的 VM 工具**，
  不是一句声明；
* 于是"发行版可以调 VM"这句话第一次有自己的宾语。

**不主张**（照 `docs/232` §9 的体例）：不主张产物因此更快、不主张 `choose vm` 会改变什么、
不主张 VM 能替代原生产物。**它今天是一个工具，不是一个编译器档位。**

⚠ 反过来也记一句：**如果哪天有人把 `choose vm` 解释成"产物交给 VM 跑"，那是另一个决定**，
需要产物携带引擎（`docs/232` §4.6 那笔欠账），不是这一次开闸附带的。

## 4. 这一轮补的是哪一半

闸的代码在 10-17 就拆了（棘轮：**替换，不删掉** —— 探针留着、期望反转，与
`use libl` #358、`choose hosted` #406 同一条；渠道常量仍被读到一次，`lspe` 那条闸还在用它，
所以 dev / release 两个种子仍然只差一个字符）。

**这一轮补的是空洞那一半**：

* `loment-lvm` 进 `loment_dist.TOOLS` —— 包里第一次有一个能跑 `.ll` 的 VM（**镜像**那份，
  走同一条自举链）；
* `loment_dist_test` 新判据**真编一次**那个工具、再拿它跑一份 `exit(42)` 的程序
  （`#355` 原话："a packaged-build test that runs one, **not just a manifest assertion**"）。

## 5. 我不主张

1. **不主张 VM 能用**（能跑 ≠ 值得跑）。`docs/226` §2.2：它比原生产物慢**两到三个数量级**。
2. **不主张三条条件永远够**。它们是为"第一天"写的；如果以后 VM 拿到了新的一档
   （比如对象级专用化），这份清单要**重新审**，而不是被当成已经通过。
3. **不主张这次开闸不可撤销**。往回关是一次同形状的改动：加回那两处拒绝、把判据 D 反转回去。
