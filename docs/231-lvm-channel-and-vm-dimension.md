> **2026-10-17 更新 —— 本片的闸已经放开。** 用户裁决：「VM 应该得开了，LVM 完成一大半」。
> 发行版现在**接受** `choose vm`。后果写清楚，免得下面几节读起来像还活着：
>
> * §2 那条拒绝规则**删掉了**（两个实现都删）；§5 判据 D 的**方向反转** —— 判据留着
>   （棘轮规矩：探针不删、期望反过来），断言从"发行版必须拒"变成"发行版必须收"。
> * **渠道机制留着，但今天没有闸再读它**：`loment_channel` 仍是"下一个还没兑现的维"
>   的注入点（拆掉渠道是另一次改动），`loment_channel_test` 那条"两个种子只差一处"
>   仍钉在 `let rel` 上。
> * **放开 ≠ 兑现**：`vm` 维今天仍是**声明**，不是保证 —— 解释器是仓侧的 `tools/lvm.py`
>   那一族（Python），发行包里没有它，产物也不走字节码。这一句与 `no_runtime` 那类维
>   同一个口径：声明先于兑现，但承诺的字面意思不许含糊。


> 状态: **规范**（2026-10-11）· 上游: `docs/229`（基座与研究）· `docs/175` §3（维度本体）·
> `docs/227`（兑现一维的先例）· `docs/158` §5（改冻结面四步）
> 一句话: **`vm` 是一维，默认 `no_vm`；而它在发行版里被编译期拒** ——
> "所有调用 VM 的都是非法的，只能 dev 可以被调用"，直到第一个可用的 LVM 诞生。
> **这一片不含 VM 引擎**：只做渠道、维度、拒绝规则与判据。

## 0. 一句话

> `choose` 已有的四维（`mode` / `gc` / `runtime` / `port`）都答"这份程序要什么"。
> `vm` 是第五维，答的是"**要哪种执行模型**"。
> 它今天**不提供任何东西**（没有字节码、没有解释器），所以它必须被**关在发行版外面** ——
> 否则 `choose vm` 会是一句发行版用户能写、却什么也拿不到的谎。

---

## 1. 这一维是什么 / 不是什么

### 1.1 取值只说"有没有"，不说"是哪一档"

| 写法 | 结果 |
|---|---|
| 不写 | **`no_vm`**（默认，与今天的行为一致） |
| `choose vm` | 声明"这份程序要由 VM 执行" |
| 同一维写两次 / 取值拼错 | **报错**（与其余四维同一条纪律） |
| `choose vm` + **发行版** | **报错**（§2） |

**为什么不写成 `vm_t0` / `vm_turbofan`。** 与 `runtime` 维同一条纪律（`docs/175` §3.6）：
装的东西会随年份长 —— 照 `docs/229` §1.5.5 那张梯子，T0 解释、T1 反馈向量、T2 基线编译、
T3 优化+去优化。把档位写进取值名，等于**把今天的内容钉成这一维的身份**，明天加一档就得回头
改定义。取值是**存在开关**，档位是被它打开的那个箱子。

### 1.2 与 `runtime` 维**正交**

`vm` 说"谁来执行"，`runtime` 说"产物里有没有运行期"。两者今天**同向**（VM 要带运行期），
但**不是同一件事**：

* `choose vm` 而 `no_runtime` —— **今天报错**，因为它会带上运行期（照 `docs/227` 那条保证）。
* 将来 VM 若做到"不拖运行期"（`docs/229` §4.2 那处"内部缺席"的延伸），这一对就该**放开**。

⇒ 所以这一片**不把 `vm` 写进 `CORE_CONFLICTS`**，而是让 `docs/227` 那条**既有的**检查
（"声明了 `no_runtime` 但它会让产物带上运行期"）自然接住它：VM 今天要用运行期，于是撞上。
**少写一条冲突，多复用一条既有规则** —— 这与那一条自己的口径一致。

### 1.3 它今天**不提供**任何东西（诚实账）

`choose vm` 编得过（在 dev 通道里）、进 Potato、每维一次 —— **但产物与 `no_vm` 逐字节相同**。
今天那个箱子是**空的**。

**这与 `docs/175` §3.6 末尾那句诚实账是同一种欠法**：`runtime` 维一度也"只声明、不提供"，
由 `docs/227` 补齐。**记在这里，别假装它是兑现的。**

## 2. 渠道闸（用户 2026-10-11 定）

### 2.1 为什么需要一个"渠道"

用户的话：**"不要在发行版 Loment 里被调用，所有调用 VM 的都是非法的，只能 dev 可以被调用，
直到第一个可使用的 LVM 诞生。"**

⇒ 需要一个"**我是发行版还是 dev**"的判据。**仓里今天没有这个概念** ——
`LOMENT_DEV` / `DEV_MODE` / `packaged` / `official` 全仓零命中（2026-10-11 查过）。

### 2.2 渠道的形状：**一个常量，一行**

两边各一处，值恒为 `dev`：

| 侧 | 位置 | 内容 |
|---|---|---|
| 自举 | `loment/selfhost/checker.lomt`（一行） | `const LOMENT_CHANNEL: u32 = 0;` —— 0 = dev，1 = release |
| 参考 | `tools/loment_channel.py`（新，一个文件） | `RELEASE = False` |

**为什么必须孤立到"一行"**：`loment_dist.py:86` 有一条本仓的明文原则 ——
包里那份 skill **原样拷、不做替换**，"这样'包里的那份 == 仓库里的那份'是**可判据的**"。
把渠道注入编译器源，**正面撞这条原则**。缩到**一行**，是让这条原则**损失最小**的形状：
包里**除了这一行**，其余每一个字节仍与仓库相等 —— **这是可判的**（§5 判据 F）。

> **⚠ 一处实测的改形（2026-10-11）**：第一版把它做成**独立模块** `loment/selfhost/channel.lomt`
> （"包里除这一个文件外逐字节相等"读起来更干净）。**落地的第一轮就撞了两件事**：
> ① 它是一份**空单元**，而"空单元的 IR 收尾"两个实现本来就**不一致** ——
> 参考实现末尾有一次 `rstrip()`，自举侧没有，差**恰好一个换行**；于是新模块引出一条
> **与渠道无关的红**。② 自举驱动器**运行期**解析 `use channel` 是另一条新路。
> ⇒ 改回**一行常量**：注入面同样是"一行"，而上面两件事都不用碰。
> **这就是 `docs/212` §0 那句话的又一次实例** —— 先量，再改形状。
>
> **⚠ 第二处实测（同一天）**：常量写进 `checker.lomt` 之后，`loment_p8_test` 的语料对照
> 在 `checker.lomt` 上又红 —— **恰好 1 字节**。定位到：`if LOMENT_CHANNEL == 1` 是
> "**常量比字面量**"，而参考实现把上下文的 `bool` 期望类型渗进了整数运算，发
> `icmp eq i1 0, 1`，自举侧发 `icmp eq i32 0, 1`。
> **这一条根因在参考实现**，而且**当天已经登记为 issue #224**（不是自举侧的错）。
> 处置：让操作数不是字面量 —— 语义一模一样，两个实现重新逐字节一致；
> **缺陷留给它自己的那一笔**，不在这个 PR 里顺手修（本仓的规矩）。
> ⇒ 结论：**加一维时，源码里每一个"常量比字面量"都可能踩这一格**。
>
> **⚠ 第三处实测（同一天，也是最贵的一处）**：绕开 #224 的第一版用的是**一个函数**
> （`fn chk_channel() -> u32 { return LOMENT_CHANNEL; }`）。**它把 60s 的护栏顶破了。**
> 同条件 A/B（背靠背跑同一条判据）：
>
> | 树 | 自举自编译 |
> |---|---|
> | 纯净 `origin/main` | **58.52s**（过） |
> | 加函数的版本 | **62.9s**（红） |
> | 去掉函数、改**局部变量** | **58.03s**（过） |
>
> 机制是已知的：**自举编译器的符号查找是线性扫，单元越大越贵**（`docs/225` §3.3），
> 而那条护栏**本来就只剩 ~1% 余量**（实测 59.33s）—— **加一个函数 ≈ +4.7s**。
> ⇒ **放宽护栏是放松门禁，不行**（`docs/225` §3.3 点名的真修法是"给那几处查找加索引"，
> 那是独立的一件事）。所以这一维在自举侧**用局部变量，不加函数**。
> ⇒ **这是一条语言面改动的成本，与它是不是"渠道"无关** —— 记在这里，因为下一个加维的人
> 会踩同一条。
>
> ⚠ 量这一条**必须 A/B 背靠背**：本机当时整体偏慢（纯净树 58.52s，而它自己的文档基线是
> 34.1s），拿绝对值跟自己几小时前的数比会得出完全相反的结论。`loment_p8_test` 那条的
> docstring 自己写着"判'这条红是不是回归'之前，先单独跑一次并且确认没有别的构建在跑"。
>
> **⚠ 第四处实测：漏了一处登记处，而它报的是「对的码、错的话」。**
> 自举侧那张**核心维词表有第二份手抄**：`loment/selfhost/switches.lomt:113` 的
> `sw_is_core`（装载器用来把 `choose X` 分成"核心维"还是"开关"）。
> **漏了 `vm`/`no_vm` 的后果**：`choose vm` 被当成**开关**去查开关表 ⇒ 查不到 ⇒
> 报 **E022「未定义的开关」** —— **码是对的、理由是错的**。
>
> **而 `loment_rule_parity` 抓不到它**：那套件只比对**码集**，三条 `vm` 负例两边都报 `22`，
> 于是判绿。**抓出它的是本片那条正向用例** —— `loment_channel_test` 里
> "dev 驱动器**必须收** `choose vm`"。这正是 `docs/232` §7 与那条既有教训
> （**孪生判据只证明"一致"，不证明"对"**）的又一实例。
>
> ⇒ **加一维要动的登记处，除了 `CORE_DIMS` 那一族、`checker.lomt` 的 `chk_core_dim`，
> 还有 `switches.lomt` 的 `sw_is_core`。** 规划阶段那份清单漏了它（它不在 `checker` 里，
> 在装载器那条线上）。⚠ 参考实现侧没有这个坑：`CORE_WORDS` / `CORE_DIM_OF` 是**推导**的
> （`tools/lomentc.py:1032/1034`），单一真源 —— **手抄的第二份才是坑**。

### 2.3 打包期注入：定点替换 + **可重算的定点相等**

`loment_dist.py` 在打包时：把自举源按原路径暂存 → **只替换 `LOMENT_CHANNEL` 那一行** →
用翻转后的树重跑 `loment_seed.py --emit` 得 **release 种子** → 由它建 stage1 → 编 `loment-driver`。

**代价（明写）**：shipped 的 `selfhost_driver.ll` **不再等于**仓库里那份。
⇒ 判据从"**逐字节相等**"降级成"**可重算的定点相等**"：

> `loment_dist --check` 必须能重算 `release 种子 = f(仓树, channel=release)` 并比对 shipped 的那一份；
> 外加一条断言"**dev 种子与 release 种子之差，恰好是 `LOMENT_CHANNEL` 那一个常量的效果**"。

⚠ **包判据里有一处必须跟着动**（2026-10-12 实测，那次 CI 里唯一的新红）：
`tools/loment_dist_test.py` 有一条"归档里的 `loment-driver` == 种子链出来的"，
它原先写死拿 **`loment_dist.SEED`（仓库那份 dev 种子）** 去链。包现在是**发行版**，
所以它必须拿**本包实际用的那个种子**（`ACTIVE_SEED`）—— 比的东西没变
（归档里的 driver 与种子链产物逐字节相同），只是那份种子**按渠道**取。
**并补一条断言**"打包必须走发行版种子"，把这件事单独钉住，免得它哪天悄悄退回 dev。

**判据没弱，反而更精确** —— 原来只能说"两份一样"，现在能说"**差在哪、为什么差**"。

### 2.4 为什么不走另外两条路

| 路 | 为什么不用 |
|---|---|
| **打包期裁掉这一维**（按哨兵注释删 12 处登记行） | ① 裁剪脚本对 12 处**脆弱**，漏一处两个实现就不一致；② release 编译器**不认识** `vm` ⇒ 只能复用"未定义的开关"，**消息不点名**，违 `docs/188` 的"宁拒勿猜" |
| **环境变量 / 命令行开关** | **发行版用户自己也能打开** —— 直接违背"发行版里调用都是非法的"。**它不是闸，是个建议** |

### 2.5 第二个上闸的维（2026-10-12）：**对外端口**

用户在同一天给了同形状的第二句话：「**锁掉 LibC，在 0.1.4.5（即将发布）中不可调用 LibC，
因为这尚未完工**」。于是 `port: hosted`（`docs/222` §4，那一维要的是真 libc / 真共享库）
上了**同一个闸** —— 细节与判据在 `docs/219` §8c，这里只记**机制上多出来的两件事**：

1. **它有两扇门，不是一个 `choose` 条**。除声明那一扇（编译器闸）之外，`--link` 那扇
   在**链接器**里，而**链接器不该知道渠道**（自举那份连常量都看不见）。
   处置：链接器对"带未定义符号的外源对象"**默认拒**，开发通道显式 `--allow-ports` 打开；
   发行版启动器**永不传**那面旗。**默认拒**是关键 —— "忘了做"的后果是开发通道不好用
   （当场发现），而不是发行版悄悄开着（没人发现）。
2. **一个常量只能用在一个 `let` 上**。`loment_channel_test` 那条"dev 与 release 两个种子
   **只差一处**"（§5 判据 F）数的是**常量被内联的位置数** —— 我给端口闸各写了一个
   `let relp: u32 = LOMENT_CHANNEL;`，种子当场差**两处**，判据红得像"注入改歪了"。
   处置：把 `let rel: u32 = LOMENT_CHANNEL;` **提到两条闸之前共用**（语义不变、
   仍是局部量、仍绕开 #224），种子回到只差一处。
   ⇒ **加一条闸时，先把渠道常量提到共用位置** —— 这是这一维的第二个可复用的教训。

## 3. 规则（一张表，照 `docs/175` §3.6 的体例）

| 情形 | 结果 |
|---|---|
| 不写 | `no_vm`（默认） |
| `choose vm`（**dev**） | 通过；进 Potato；产物与 `no_vm` **逐字节相同**（§1.3） |
| `choose vm`（**release**） | **报错**，点名"发行版不含 VM，这一档只在开发通道可用"，并给修法 |
| `choose vm` 写两次 | 报错（每维一次） |
| `choose vm` + `no_runtime` + 用到运行期 | **由 `docs/227` 既有那条接住**（§1.2），不新写冲突 |
| 库写 `choose vm` | 按 `docs/227` 放宽后的规则：**视作需求，根须满足** |

**同一维写两次 / 未定义的开关 / 库不许** 三类消息**共用 E022** —— 与 `runtime` 维那三条
同一个码、同一个理由（用户要做的是同一件事）。**不新开诊断码。**

## 4. 代价（明写）

1. **默认档逐字节不变**（`docs/175` §3.4 那条"默认不变"；`docs/227` 判据 E 是它在
   最近一维上的量法）：不加 `choose vm` 的语料，产物**一字不动**。
   这一片**唯一的产物级改动**是 Potato 升版（§5 判据 C），IR 不动。
2. **渠道机制是新的**，仓里以前没有。它买到的**不是安全**，是**"发行版里调不到"这句可判**。
3. **shipped 种子不再逐字节等于仓库那份**（§2.3）—— 用"可重算的定点相等"替代（判据 F）。
4. **自举编译器会长大** → 可能撞 `lomelf` 的标签表（`TB_LBL_MAX`，`docs/200`；`docs/227` §6
   记着同一条）。加完**立刻按 `docs/200` 量**，撞了照那条修法走。

## 5. 判据（每条可证伪）

| # | 判据 | 证伪方式 | 落点 |
|---|---|---|---|
| **A** | **每维一次 / 取值合法** | `choose vm` 写两行 ⇒ 必须报；`choose vm_x` ⇒ 必须报。两个实现**码集相等** | `loment_rule_parity` 新用例（`BUDGET` 棘轮上调） |
| **B** | **dev 接受** | `choose vm` 在仓里**必须编过**，且与不加它的产物**逐字节相同** | `loment_p8_test` |
| **C** | **进 Potato 且可判** | 从产物对象里删掉 `vm` 键 ⇒ 独立校验器**必须红**；`vm` 档可读 | `potato_test` 新夹具 + 两份校验器 |
| **D** | **发行版拒**（本片的核心） | 用 **release 渠道**编的 driver 跑 `choose vm` ⇒ **rc ≠ 0 且消息点名**；同一份源跑 dev driver ⇒ rc = 0 | 打包侧端到端（**CI**，照 `docs/202`"真装真跑"） |
| **E** | **默认档逐字节不变** | 现有语料（不加 `choose vm`）⇒ 产物**逐字节不变** | `loment_potato_emit_test` 逐字节孪生 |
| **F** | **可重算的定点相等**（§2.3） | `loment_dist --check` 重算 release 种子并比对 shipped；且 dev 种子与 release 种子之差**恰为** `LOMENT_CHANNEL` 那一个常量的效果 | 打包侧（CI） |
| **G** | **两个实现一致** | `vm` 相关的静态那一半，参考实现与自举侧**逐字节相同** | `loment_seed_test` + `loment_p8_test` |

**这一节的规矩**（照 `docs/210` §5）：每条要么有一个**反例**，要么有一对**程序**。
只钉"某个形容词成立"的不算。

## 6. 我不主张

1. **不主张这一维今天有用。** §1.3：那个箱子是空的。这一片买到的只有"**关得住**"。
2. **不主张渠道机制是对的长期形状。** 它是**临时的** —— 第一个可用的 LVM 诞生时，
   `vm` 就该在发行版里放开，这套渠道闸**要么拆掉、要么留给下一个未兑现的维**。
3. **不主张 `vm` 与 `runtime` 永远正交。** §1.2 那条判据是"今天"，VM 做到不拖运行期时它要重看。
4. **不主张判据 A–C、E–G 已经跑过。** 本片落地时才跑；D 与 F **只能上 CI**（本机只跑单条归因）。
