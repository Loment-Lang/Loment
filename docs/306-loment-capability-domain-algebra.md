## 0. 为什么要把一个区间拆开

现行定义（`docs/146` §1）是四元组

```
D = (space, lo, hi, revocable)
```

它把三件事焊死在一个声明里：

| 焊死的 | 后果 | 松动它的是 |
|---|---|---|
| 形状只能是**闭区间**，两端有限且都包含 | 写不出"从 9 往后都行" | 前无限域 / 后无限域 |
| 极性只有一种：**在区间内就放行** | 写不出"这几页禁止碰" | 危险域 |
| 行为**不随时间变**（编译期常量表） | 写不出配额、滑动窗口、代 | 时类 |

拆开之后是四个正交维度：

```
域 = 空间(space) × 形状(shape) × 极性(polarity) × 时律(time law)

一般类：时律 = ⊥（没有时间原点）
时类  ：时律 ≠ ⊥（有 Time in Domain）
```

`revocable` 不再是独立维度：它是时律里的一个终态（§5.2 的撤销）。

## 1. 形式核心

### 1.1 域是一个带极性的谓词

```
D = (S, P, π, λ)

S  空间     位置的全集（今天由 capability 的 space 名字给）
P  形状     P ⊆ S，域"点名"的那些位置
π  极性     allow：通过 ⟺ x ∈ P；deny：通过 ⟺ x ∉ P
λ  时律     ⊥（一般类）或一条时律（时类），λ(t) 给出当前实例的 P 与 π
```

`guard` 的语义从 `docs/146` §2 推广成：

```
guard c(e):
  x    = eval(e)
  inst = current_instance(c)            # 一般类：唯一实例（编译期常量）
  ok   = (x ∈ shape(inst))  if polarity(inst) == allow
         (x ∉ shape(inst))  if polarity(inst) == deny
  if not ok: reject(c, x)               # trap，或危险域的闭锁（§3.3）
  audit[c] += 1
```

`docs/146` 的 S1–S3 三条健全性断言逐字保留，只是把"`[lo,hi]`"换成"`shape(inst)`"。

### 1.2 静态规则要跟着对偶

`docs/146` §3 的静态规则只覆盖 allow 一侧。推广后两边各一条：

| 情形 | allow（安全域） | deny（危险域） |
|---|---|---|
| `e` 是字面量且**不通过** | 编译错误（越界） | 编译错误（**落在禁止区内**） |
| `e` 是字面量且**通过** | 放行（运行期检查可折掉） | 放行（同左） |
| `e` 非字面量 | 运行期判 | 运行期判 |
| 能力未声明 / 空间被 `excluded` | 编译错误 | 编译错误 |

第二列的第一行是新的：一个**字面量必然被拒绝**的 guard 是死代码，和字面量越界一样是错误。

## 2. 一般类：五个形状

### 2.1 定义

一般类形状 = 空间里的**一个连通区间**，两端各取 `ℤ ∪ {−∞, +∞}` 中的一个，且 `lo ≤ hi`。

### 2.2 五种，且只有五种

按**有限端点的个数**分类：

| 名称 | 记法 | 有限端点 | guard 的比较 | 今天 |
|---|---|---|---|---|
| 点域 | `[a..a]` | 2（重合） | `x == a` | ✅ 已可写 |
| 常规域 | `[a..b]`，`a<b` | 2 | `a ≤ x ≤ b` | ✅ 已可写 |
| 前无限域 | `[()..b]` | 1（上端） | `x ≤ b` | ❌ |
| 后无限域 | `[a..()]` | 1（下端） | `x ≥ a` | ❌ |
| 全域 | `[()..()]` | 0 | 恒真 | ❌ |

**穷尽性（小证明）**：连通非空区间由 `(lo, hi)` 唯一确定，`lo ∈ ℤ∪{−∞}`、`hi ∈ ℤ∪{+∞}`、
`lo ≤ hi`。数有限端点 `k ∈ {0,1,2}`；`k=2` 再按 `lo<hi` / `lo=hi` 二分。五种互斥且覆盖全部。∎

### 2.3 一个必须先讲清的坑：u64 空间里"前无限"会退化

今天的 `lo`/`hi` 是 `u64`（`tools/lomentc.py` 的 `parse_capability` 走 `int_lit()`），
空间的自然下界是 `0`。所以在今天的载入下：

```
[()..8]  ≡  [0..8]
```

**前无限域只有在空间"没有天然零点"时才有内容**——即空间声明了自己的载体：

- `u64` 下界 0：前无限退化，后无限有意义（`[9..()]` = "9 往后都行"，一次比较）；
- `i64` 无界：两者都有意义；
- 符号空间（`named`）：序不成立，属于 §7 的枚举域。

⇒ 落地时空间要带一个**载体声明**，而不是硬编码 `u64`。这是 `space` 面的变更，不是形状面的。

### 2.4 一般类不封闭于补集 —— 这是分段域存在的理由

```
S ∖ [a..b] = (−∞..a−1] ∪ [b+1..+∞)
```

右边是**两个**区间，不是五种形状里的任何一个。所以：

> 五种一般类形状对补集不封闭 ⇒ 表达"补集"必须有复合形状。

复合形状（**分段域**）不是第六种一般类，是 `∪` / `∖` 的**派生结果**，落在 §6 的
域图里（一个安全域减去一个危险域 = 一个带洞的安全域）。这样"5 种"仍然是穷尽的。

## 3. 极性：安全域与危险域

### 3.1 对偶

| 极性 | 通过条件 | 默认 | 扩大域 | 缩小域 | 典型用途 |
|---|---|---|---|---|---|
| **安全域**（allow） | `x ∈ P` | 拒绝 | **扩权**（需确认 + 审计） | 安全 | 常规能力 |
| **危险域**（deny） | `x ∉ P` | 允许 | 安全 | **扩权** | 隔离区、坏页、绊线 |

两者是同一个东西的两面：`allow(A) ≡ deny(S ∖ A)`。**"安全/危险"不是两种域，是同一个
谓词前面的一个否定号**；编译器只需要在发射比较时翻转跳转。

### 3.2 单调律（安全方向的变更）

```
安全域：只许收缩；扩一次要一次显式确认。
危险域：只许扩张；缩一次（= 放出一块禁区）要一次显式确认。
```

这不是新发明的规则——内核 `dom_admit`（`0x8313`）的语义就是
**"quality→domain width; WIDEN_CONFIRM windows; shrink immediate"**，即安全域一侧的这条律。
危险域一侧是它的镜像，今天没有原语（§10 里列为可选项，不是第一阶段）。

### 3.3 危险域是**绊线**，不是过滤器

一个设计选择，需要你裁（§11 开放问题 1）：

- **过滤器**：危险域只是一块禁止区，每次进都拒，程序继续跑。
- **绊线（闭锁）**：第一次碰到危险区就**把整个域闭锁**，之后所有 guard 全拒，
  只能由工具域复位。

我倾向绊线。理由：危险域的价值在于"这件事**本来不该发生**"——`docs/208` 的整个思路
是"能不能发生"要能被判据抓住，而不是被静默过滤掉。闭锁把一次越界变成一次**可观察的停机**，
过滤器则把它变成一条容易淹没的审计条目。代价是：危险域不能用来做"软隔离"。

## 4. 时类：时间原点与实例

### 4.1 术语

```
TiD（Time in Domain） = t₀       域的时间原点；一般类没有 TiD
域龄                  = t − t₀   当前实例活了多久
实例 I_k              = (t_k, shape_k, polarity_k, id_k)
时律                  = 从 I_k 产生 I_{k+1} 的规则
```

时类域不是"一个域随时间变"，而是**一列一般类实例**。`guard` 判的是"当前实例"。

### 4.2 时钟必须是虚拟的

**时类域的时间只在安全点前进**（与热更新、GC 用的是同一批安全点，`docs/246`）。

| | 墙钟 | 虚拟安全点钟（本文选这个） |
|---|---|---|
| 确定性 | 不可复现，判据只能测区间 | 逐字节可复现 |
| 定时器 | 要线程/信号 | 无 |
| 与 GC/热更新 | 两套时钟 | 同一套 |
| 代价 | —— | 程序不主动进安全点就不推进 |

墙钟只能通过一个显式的 `clock` 能力读取，且读取本身进审计——否则时类域可以被轮询反推。

### 4.3 实例身份与"陈旧守卫"

每个实例有自增的 `id_k`。guard 有两种绑定：

```
guard  c(x);      # 当前实例：每次重新读 id
guard@k c(x);     # 钉住实例 k：若当前 id ≠ k，抛"陈旧实例"
```

第二种是抓 use-after-free / 悬垂句柄的钩子：句柄带着它签发时的实例号，代域换代后
旧句柄必然撞上"陈旧实例"而不是静默读到新对象。

## 5. 八条时律

分成两族：**续期族**（范围定长，问"什么时候开一个新实例"）与
**变形族**（不靠开新实例，而靠改域本身）。

### 5.1 续期族（4 条）

| # | 名称 | 原点怎么走 | 形状 | 一句话 | 典型用途 |
|---|---|---|---|---|---|
| 1 | **纪元域** `epoch` | 不走 | 定长 | 只有一次；用尽即**失效**，不续 | 一次性配额、启动纪元、一次性票 |
| 2 | **遥远域** `far` | **走到界就跳** | 定长 | 走到末尾，末尾当成新原点开下一段 | 环形缓冲分段、日志轮转、EBR 纪链 |
| 3 | **滑窗域** `sliding` | 随钟连续走 | 定长 | `[t−w..t]`，错过的永远错过 | 最近 N 秒的追踪、速率窗口 |
| 4 | **周期域** `cyclic` | 按周期回绕 | 定长 | 每 `P` 重置；位置对 `P` 取模 | 每帧/每 tick 的桶、环形槽位 |

它们是同一个东西的不同量化：

```
滑窗  ──(把钟量化成段)──▶  遥远  ──(段首尾相接)──▶  周期
  │                          │
  └──(w 不变，原点永不回绕)──▶ 纪元（只开一段，不开下一段）
```

用户给的"遥远域"就是 #2：`t_{k+1} = end(I_k)`。它的两个变体：

- **有限遥远**：`shape_k = [t_k .. t_k+w)`，有界，走得到头 ⇒ 会续；
- **无限遥远**：`shape_k` 没有右端，**永远走不到头** ⇒ 原点不会因耗尽而走，
  只能由一次显式的"退休"事件推进。这是"有限/无限"的真正区别，不是两套机制。

### 5.2 变形族（4 条）

| # | 名称 | 原点 | 范围怎么变 | 一句话 | 典型用途 |
|---|---|---|---|---|---|
| 5 | **生长域** `growing` | 不动 | 单调**增** | 前端钉死，后端一直长 | 预算充值、累积信用 |
| 6 | **衰减域** `decaying` | 随钟走 | 单调**减** | 后端钉死（截止点），前端推进 | 剩余寿命、TTL、信任半衰 |
| 7 | **自适应域** `adaptive` | 慢走 | **反馈驱动** | 宽度跟质量账本；扩需确认，缩立即 | 信任自适应授权 |
| 8 | **代域** `generational` | 按代走（安全点） | 形状不变，**极性翻转** | 旧实例不消失，转成危险域 | 悬垂句柄、EBR、热更新重映射 |

第 7 条**内核里已经有了**：`dom_admit` + `qual_feed` + `qual_seq`
（`lom/fuai.lom` 0x8313/0x8314/0x8315）就是"质量 → 域宽"的闭环。语言侧目前没有表示，
所以今天这句话只有内核一半。本文补的是语言侧的形状。

第 8 条是唯一一个**不改形状、改极性**的时律：第 k 代是安全域 `[a..b]`，换代后同一个
`[a..b]` 变成危险域。它和 `docs/246` 的安全点、GC 的代、热更新的重映射是同一个结构——
所以它不需要新机制，只需要接到已有的安全点上。

### 5.3 为什么正好是 8

两条独立的律：**原点律**（不走 / 到界走 / 随钟走 / 按周期走）与**范围律**
（定长 / 增 / 减 / 反馈）。8 = 定长 × 四条原点律（#1–#4）+ 四条"改域本身"
（#5–#7 改宽度，#8 改极性）。

判据是三项都可检验：

1. **一个计数器 + 一次比较**就能实现；
2. **闭式**（除 #7 要读账本外，不需要外部预言机）；
3. **有 L0 面**（§10 的表逐条对上）。

不满足这三条的（租约、潮汐、按墙钟的截止）**不是第 9 条时律**，而是 §6.3 的扩展域
复合出来的——例如 **租约 = 纪元域 ⊕ 扩展域(续租事件)**。

## 6. 组合：域树、域图、扩展域、工具域

### 6.1 域树（包含）

- 节点 = 一个域声明；边 = **细化**（子 ⊆ 父）。
- 一个父 ⇒ 树。根 = 工具域（或全域）。
- 不变量：
  - **C1（封顶）**：任何时刻 `child ⊆ parent`。一般类是编译期证明；时类在**每次扩展时**核。
  - **C2（撤销级联）**：撤销父 ⇒ 整棵子树拒绝；已撤销的 id **不复用**（墓碑，防 ABA）。
    **已实装**：`revoke NAME;` / `revoke NAME(x);`（`docs/315` §1.7）。级联是守卫链的
    性质，不需要传播指令；墓碑落地为"顶层能力的撤销位在全局表里、置起后不复位"。
- 为什么是树：编译器要一个**良基序**来证包含，不想上求解器。树给了它。

### 6.2 域图（关系）

有向带标号多重图。边的种类：

| 边 | 含义 | 检查点 |
|---|---|---|
| `⊆` 包含 | 细化，必须与树一致 | 编译期 / 扩展时 |
| `⊥` 互斥 | 两个域永远不会同时接纳同一个位置 | 编译期（常量）/ 运行期（动态） |
| `×` 排他 | 同一时刻不能同时持有两个 | 运行期 |
| `→` 委托 | a 可把子集授予 b | 运行期 + 审计 |
| `⊕` 合并 | 复合形状 | 编译期 |
| `≺` 时序 | 实例 k 在 k+1 之前 | 虚拟钟的总序 |
| `⇄` 联动 | 两个域一起续期 | 续期事件 |

设计关系：

> **树是图里 `⊆` 边的生成树。**
> `⊆` 子图必须无环（良基）；`≺`/`⇄` 允许有环，但由虚拟钟的全序打破。
> 危险域是**减法边** `∖`：安全域里的一个洞，不新增形状（§2.4）。

一个安全域减去一个危险域，就地得到一个"带洞"的复合形状，不用引入第六种形状。

### 6.3 扩展域（扩展）

```
E = (host, δ, trigger)
δ      有符号的形状增量（加位置 / 减位置）
trigger 时刻 / 事件 / 宿主耗尽 / 质量阈值 / 外部调用
```

规则：

1. **扩展本身是一次能力**——施加 E 需要工具域的权利；
2. 扩展必须**尊重父域的余量**（C1），所以扩权在本地可证，不需要全局求解；
3. 每一次施加都进审计；
4. **安全方向免费**（缩），**危险方向要显式扩权令牌**（扩）——与 §3.2 同一条律。

它把好几件事统一了：

```
租约   = 纪元域 + 一次扩展（续租事件）
生长   = 周期施加的扩展（加）
滑窗   = 前端加、后端减（δ 的两半）
远域续期 = 耗尽触发的扩展
```

### 6.4 工具域（元层）

**唯一一种成员是"对域的操作"的域**：`create / bind / revoke / widen / extend / retarget`。

- 它直接对上 L0 已有的 `dom_create`(0x8107) / `dom_bind`(0x8108) /
  `dom_revoke`(0x8109) / `dom_info`(0x810A) / `dom_admit`(0x8313)。
- **单层原则**：工具域的权利**不传递委托**——能改域的能力不能再被委托出去。
- 因为它能加宽一切，它在根上只能是**危险域**（或者根本不给）。

> 另一个读法（"工具域 = 以工具 id 为成员的域"）不需要新概念：那只是 §7 的
> **枚举域**，一个一般类形状。两种读法在这里合流。

## 7. 我补的概念（除了你列的）

| 概念 | 定义 | 为什么需要 |
|---|---|---|
| **分段域** | 有限个区间的并 | 五种形状对补/并不封闭（§2.4）；洞与多段只能这样表达 |
| **域余量** slac | 当前域到父域边界还差多少 | 让"扩权"在本地可证，不必全局算 |
| **域龄** age | `t − t₀` | 时类的可观察量；进审计与诊断 |
| **实例号** id | 自增，墓碑不复用 | 抓陈旧句柄；防 ABA |
| **域闭锁** latch | 危险域首次越界后整域封死 | 绊线语义（§3.3） |
| **域不透明** | 只回答"在不在"，不回答"有哪些" | 否则枚举就是侧信道（接 `docs/208`） |
| **生命周期状态机** | 未生 → 活 → 冻结 → 失效/撤销 → 闭锁 | 撤销、过期、闭锁要能区分 |
| **可判三档** | 常量静态 / 动态一次比较 / 时类实例化 | 编译器不能因为推广而**静默丢掉**今天的静态检查 |
| **枚举域** | 成员是显式集合，不是区间 | 非序空间（路径、工具 id、符号名） |
| **跨空间禁止** | 一个域只属于一个空间 | 否则"包含"没有意义 |

## 9. 判据（实装时每条都要先红）

| 判据 | 喂什么 | 期望 |
|---|---|---|
| 形状 × 极性 | 五种形状 × `{lo−1, lo, hi, hi+1}` × 两种极性 | 逐格 pass / trap 与手算一致 |
| 静态对偶 | 字面量落在危险区内 | **编译错误**，不是运行期 trap |
| 穷尽性 | 随机形状反查分类器 | 必落在五种之一，不重不漏 |
| 时律续期 | 推进虚拟钟跨过每个边界 | 实例号**恰好**加一，不多不少 |
| 陈旧实例 | 换代后再用旧 `@k` 守卫 | 抛陈旧实例，不静默放行 |
| 封顶 | 子域扩到父域外 | 编译期拒（常量）/ 扩展时拒（动态） |
| 撤销级联 | 撤销父 | 全子树拒绝，审计条目数 = 子树 guard 次数 |
| 互斥 | 两个 `⊥` 域随机 fuzz 同一位置 | 永不同时接纳 |
| 闭锁 | 危险域越界一次 | 之后全拒；复位只有工具域能做 |
| 不透明 | 试图枚举域成员 | 语言层面没有入口（不是运行期拒绝） |
| 双实现 | 同一份源 | `tools/lomentc.py` 与 `loment/selfhost/*.lomt` 逐字节一致（`docs/158` §5） |

**注意**：静态那一档（常量字面量）必须仍然静态。推广成动态之后"能过编译但每次运行都 trap"
是**倒退**，判据要钉住它。

## 10. 落地阶梯与 L0 影响

**好消息：第一阶段不需要动 L0。** 逐条对：

| 能力 | 需要的原语 | 今天有吗 |
|---|---|---|
| 生命周期（建/绑/撤/查） | `dom_create` / `dom_bind` / `dom_revoke` / `dom_info` | ✅ `lom/fuai.lom` 0x8107–0x810A |
| 宽度自适应 | `dom_admit` / `qual_feed` / `qual_seq` | ✅ 0x8313–0x8315 |
| 虚拟钟 | 编译器在安全点插 tick | 纯 L1 + 已有安全点（`docs/246`） |
| 实例状态 | 全局静态槽 | 纯 L1 |
| 树/图检查 | 检查器 | 纯 L1 |
| 扩展域 | 一次带审计的赋值 | 纯 L1（第一阶段） |

所以阶梯是：

| 级 | 内容 | 改哪里 | 需要 L0 契约变更？ |
|---|---|---|---|
| S1 | 五种形状 + 极性 + 静态对偶 | `lomentc.py` + selfhost + 判据 | 否 |
| S2 | 域树 / 域图 / 余量 / 撤销级联 | 检查器 | 否 |
| S3 | 虚拟钟 + 实例 + **纪元 / 遥远** | 编译器插安全点 | 否 |
| S4 | 滑窗 / 周期 / 生长 / 衰减 | 同上 | 否 |
| S5 | 代域（接 GC / 热更新安全点） | 与 `docs/246` 对齐 | 否 |
| S6 | 自适应（读账本） | 读 `qual_seq` | 否（只读已有） |
| S7 | 工具域作为 L1 门面 | 包 `dom_*` | 否 |
| — | **内核强制的时类域**（跨进程撤销、外部加宽） | 新原语 | **是**，单独一次提交 + 知会 compat 线 |

也就是说：能力域这一批**可以先全在语言侧落地**，把"内核要不要也认时类"留成一个
显式的、可推迟的契约决定。这是本设计能同时激进又不撞冻结面的关键。

## 11. 不做 / 开放问题

**不做**：

- 不做墙钟域（只能通过显式 `clock` 能力读墙钟，见 §4.2）；
- 不做 L1 动态建域（要 L0 契约，见 §10 最后一行）；
- 不做跨空间域（§7）；
- 不把危险域当"软隔离"用（若 §3.3 选绊线）。

**需要你裁**：

1. **危险域是过滤器还是绊线？**（§3.3）——我倾向绊线。
2. **前无限域在 u64 下退化成 `[0..b]`**（§2.3）——是给空间加载体声明（`i64` / `named`），
   还是承认它只在非序空间里有意义？
3. **第五个一般类用"全域"还是"枚举域"？**（§2.2 / §7）——本文选了全域（为了穷尽性），
   枚举域被放进"空间种类"这一维；若你更想要枚举，两者可以换位。
4. **第八条时律用"代域"还是"租约域"？**（§5.2）——本文选代域（它接已有安全点），
   租约被降成"纪元 ⊕ 扩展"的复合。

## 12. 实装状态（2026-11-06）

**已实装全部 18 种**，两套实现（`tools/lomentc.py` + `loment/selfhost/*.lomt`）逐字节对齐：

| 维度 | 已实装 | 写法 |
|---|---|---|
| 形状 | 常规 / 点 / 前无限 / 后无限 / 全域 | `[a..b]` / `[a..a]` / `[()..HI]` / `[LO..()]` / `[()..()]` |
| 极性 | 危险域 | `... danger` |
| 时律 | 纪元 / 遥远 / 滑窗 / 周期 / 衰减 / 生长 / 自适应 / 代 | `epoch(N)` / `far(N)` / `sliding(N)` / `cyclic(P)` / `decaying(N)` / `growing(N)` / `adaptive` / `generational(N)` |
| 语境类 | 消耗 / 主体 / 见证 / 流向 / 可达 | `consumed(N)` / `subject(MASK)` / `witnessed(N)` / `flow` / `reachable(K)` |

**虚拟钟**：`tick;` 语句把 `@__loment_now` 加一。除 `consumed` / `witnessed` / `reachable`
外，所有时律都是 `now`（或位置）的**纯函数**。

**判决点**：两个后端都发
`@__loment_guard2(st, cap, idx, aux, lo, hi, kind, param, flags, rv)`（Rust 侧同名函数，
2026-11 起 IR 多了 `rv`）。
`aux` 是语境类的第二个实参（主体号 / 票号 / 目标节点），其余一律 0；`flags` 的 bit0 / bit1
是下端 / 上端无界。`rv` 指向这一层的**撤销位对**（`docs/315` §1.7：C2 的落地形状）——
不可撤的域传共享零格 `@__loment_revfree`。审计仍只在**放行支**加一（`docs/146` 属性 1/2 不变）。

**七种新域的可观察语义**（`kind` 编号见 `CAP_KIND_ID`）：

| # | 写法 | 通过条件 |
|---|---|---|
| 8 | `cyclic(P)` | `(idx % P)` 落在形状里；要求 `P > hi`（静态检查） |
| 9 | `generational(N)` | 形状不变，**极性随代数翻转**：`in(idx) ≠ ((now/N) & 1)` |
| 10 | `adaptive` | 宽度随质量缩放：`idx ≤ lo + (hi−lo)·q/255`；`quality cap = q;` 喂 0..255，默认 255 |
| 11 | `subject(MASK)` | `in(idx) ∧ (MASK >> (aux & 63)) & 1`（`aux` = 主体号） |
| 12 | `witnessed(T)` | `in(idx) ∧ wit[cap][aux & 63] < T`，放行后该票计数 +1（`aux` = 票号） |
| 13 | `flow` | `(idx << 16 | aux & 0xffff)` 落在形状里（形状是**打包后的边**，`idx` = 源、`aux` = 目标） |
| 14 | `reachable(K)` | `in(idx) ∧ obl[cap][idx & 63] = 0`，放行后登记 `now+K`；`discharge cap(x);` 结清，过期或未登记都 trap |

**语言侧约束**（两套实现都判）：

- 时律参数 ∈ (0, 2^24)（自举侧把它打包进表项剩下的 24 位）；
- `consumed` 与 `reachable` 必须有界，且域宽 ≤ 64（每格一个计数器 / 义务槽）；
- `cyclic` 要求有界且周期 > 上界；`generational` / `adaptive` / `flow` 必须有界；
- `subject` / `witnessed` / `flow` **必须**带第二个实参，其余律**不接受**第二个实参；
- `quality` 只用于 `adaptive`，`discharge` 只用于 `reachable`；
- 静态字面量检查覆盖 `regular` / `danger` / `cyclic`（回绕后判）——其余依赖钟或第二实参；
- 无界侧在 `CapDomain` / `@__loment_caps` 里用 0 / MAX 表示（表仍是四元组）。

**诚实边界**（这七条都是"语言侧可判的那一半"，不是完整语义）：

- `subject` 的主体号是**调用方给的实参**，不是不可伪造的令牌（那要线性值，见 `docs/307` §10）；
- `witnessed` 的票号同样是实参：语言只保证"同一张票只能用 T 次"，不保证票不可伪造；
- `flow` 的形状是**打包边的一个区间**，不是任意边集（一般边集要改 IR 数据形状，见 §10 C4）；
- `reachable` 是 `docs/308` §2.4 的 **dynamic 档**：登记 + 期限 + 结清，不是有界模型检查；
  期限在"该域的下一次事件"（guard / discharge）上核，不靠 `tick` 扫描；
- 周期域没有"每格时间戳"，代域没有接 GC/热更新的安全点 —— 它们是时钟的纯函数。

**仍未实装**：域树 / 域图 / 扩展域 / 工具域（§6）、`docs/308` 的嵌套与驱动环、
以及 `reachable` 的静态有界检查（C5，独立工具）。**没有动 `lom/*.lom`**。

**域进入代码**：块级域（`domain NAME : SPACE[lo..hi] { … }`）、值的空间标签
（`let a: [u32; 64] in disk`）与自动守卫见 `docs/314`；顶层 `capability` 仍是整单元的形式。
