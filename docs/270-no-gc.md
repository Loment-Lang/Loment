# 270 · `no_gc` —— 把「产物不带收集器」变成一句**可判的话**

> 状态: **规范**（2026-10-19，issue #538）· 上游: `docs/175` §3.4（回收档的三种语义）·
> `docs/210` §4.5（"正常的形态是没有叫 GC 的组件"）· `docs/227`（`no_runtime` 的保证，
> 本页是它的镜像）· `standard/LLS.md` §4.5 → §4
> 一句话: `no_gc` 不是第四个"更自动"的档，而是**把已经存在的性质写成程序自己的声明** ——
> 并且**由链接器核它**。

---

## 1. 它说什么

`choose no_gc` 声明：**这件产物里没有收集器**。

它**不**说"程序不分配内存"。一个在运行前就把分配全部结清的程序，结束时的 L3 残差是 0、
产物里没有收集器 —— `docs/210` §4.5 把这种形态叫"正常"；`no_gc` 让程序把这句话**说出来**。
分配与手动归还仍然存在（那是 `gc_manual` 的语义），区别在于**产物里有没有收集器**。

LLS §4.5 原先把它列在"计划值"里，并明说"标准不是放计划的地方"。这一页就是它要的那份记录。

## 2. 它改什么

| 面 | `no_gc` 之后 |
|---|---|
| 参考实现 | `CORE_DIMS["gc"]` 的第四个值；`choose no_gc` 接受 |
| 自举实现 | `sw_is_core` / `chk_core_dim` / `chk_core_val` 同一张表；Potato 记录 |
| Potato（产物） | `gc` 字段写 `no_gc` —— **不读源码可判** |
| IR | 多一行 `; loment-gc: no_gc`（**只有它**多发这一行，其余档的 IR 一个字节不变） |
| 链接器（两份） | 读到那行时核 IR 里真的没有 `@__loment_collect` / `@__loment_roots` |
| 代码发射 | 与 `gc_manual` 相同：不追加收集器与根表 |

**它不与任何一维冲突。** `no_gc` 与 `no_std`、`no_runtime`、`sealed`/`hosted`、
`lms_*`、`lspe_*` 都可以并存：那些维说的是"用哪一层/有没有运行期/通不通世界/要不要
内存安全/要不要审计"，而 `no_gc` 只说"没有收集器"。它与两个自动档不能"并存"的原因
不是冲突表，而是**同一维只能有一个值**（`docs/175` §3.0）：写了 `no_gc` 就不能再写
`gc_auto`。

## 3. 带牙的地方

`docs/227` 判据 B 的形状在这里重来一遍：

> **声明了 `no_gc` 而产物里带着收集器 ⇒ 拒绝。**

编译器是那句声明的作者，所以检查放在**链接器**：它拿到的 IR 可以不是自己生成的。
两份链接器（`tools/lomelf.py` 与 `loment/tools/lomelf.lomt` 的镜像）同一条判断、同一处失败。

判据：

- `loment_choose_matrix_test::test_no_gc_is_accepted_and_the_linker_checks_the_claim`
  —— 编得过、产物无收集器、**伪造**的声明在链接期点名拒（参考实现）；
- `loment_elf_test::test_both_linkers_check_a_no_gc_claim_against_the_collector`
  —— 两份链接器：诚实的收，伪造的拒。

## 4. 标准怎么变

`standard/LLS.md`：

- `no_gc` 从 §4.5（计划值）移进 §4 的表 —— 它不再是"计划"，是核心取值；
- §4.5 留着那句"值可以先于实现存在"，但表清空（今天没有别的计划值）；
- 标题版本 `0.1.4.6 → 0.1.4.7`，与 `tools/loment_release.py:RELEASE` 对齐（§6.4 说
  这两个数是**同一个**；此前正文落后了一个版本）。

## 5. 边界（别当成缺陷重开）

- `no_gc` **不禁止分配**；它只说产物里没有收集器。要"连分配也不许"，那是另一个值
  （目前没有，也不在本里程碑）。
- 它**不改变** L0/L1/L2 的编译期梯子：那些是 `gc_auto_alpha` 的 L2 与 alpha 的优化，
  与"有没有收集器"不是同一件事。
- 自举侧的 Potato 校验器（`lompotato.lomt`）里，`no_gc` 与自动档的互斥**不写成冲突** ——
  同一个校验器里，"一维两值"由"这一维只能声明一次"那条先接住。
