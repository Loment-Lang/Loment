# 321 — `world` 包：现实世界的 19 块对照

`docs/317` 拆领域包时 `world` 只有 `money` 与 `geo` 两块 —— 货币与坐标。
现实里"要跟世界对上"的东西远不止这两样：日期、时区、语言标签、证件号、
地址、人名、相对时间。这一份补 19 块，`world` 从 2 个内容模块变成 21 个。

## 落了什么

| 模块 | 公开面 | 解决什么 |
| --- | --- | --- |
| `calendar` | `cd_*` | 公历 ↔ 天数、星期、ISO 周、月份加减（Hinnant 算法） |
| `holiday` | `hd_*` | 复活节（Meeus）、第 n 个星期几、最后一个星期几 |
| `tzoff` | `tz_*` | UTC 偏移解析/格式化、epoch ↔ 当地时间 |
| `dateparse` | `dp_*` | 严格 ISO 8601 日期/时间解析与格式化 |
| `timeago` | `ta_*` | "3 hours ago" / "in 2 days" 的阈值与单复数 |
| `geohash` | `gh_*` | geohash 编码/解码（微度整数输入） |
| `flag` | `fg_*` | ISO 两字母码 ↔ 国旗 emoji（区域指示符算术） |
| `langtag` | `lgt_*` | BCP 47 语言标签解析与大小写规范化 |
| `phone` | `tel_*` | E.164 归一化与北美格式 |
| `postal` | `zip_*` | 20 国邮政编码形状检查 |
| `isbn` | `isbn_*` | ISBN-10/13 校验与 10→13 转换 |
| `ean` | `ean_*` | GTIN-8/12/13/14 校验位、UPC-A→EAN-13 |
| `iban` | `iban_*` | 30 国 IBAN 长度 + mod-97 |
| `luhn` | `luhn_*` | 支付卡 Luhn 与品牌前缀 |
| `slug` | `sl_*` | 标题 → URL slug（折叠分隔符、去首尾） |
| `translit` | `tl_*` | 西里尔/希腊 → 拉丁（含重音希腊字母） |
| `namefmt` | `nmf_*` | 人名拆分（称谓/后缀/名/姓）与 `Lovelace, Ada` |
| `words` | `nw_*` | 整数 → 英文基数词/序数词（到万亿） |
| `roman` | `rm_*` | 罗马数字 ↔ 整数（拒绝 `IIII` / `IL`） |

## 几条设计边界

- **能算法化的就不带表**：日期、时区偏移、geohash、Luhn、IBAN 的 mod-97、
  罗马数字都是纯算法；只有 IBAN 长度与邮政编码形状各带一张小表，且都是
  **结构**（长度/字符类别），不是会过期的注册数据。
- **宁可拒绝，不要猜**：`roman` 拒绝非标准写法；`dateparse` 拒绝 `2024-02-30`；
  `patch`（`dev`）拒绝上下文不符的补丁 —— 同一个取向。
- **整数坐标**：`geohash` 用微度 i32，避免在库里引一套 f64 比较；8 位格约 19 m，
  已经在微度（0.11 m）能表达的范围内。
- **返回完整长度**：所有写缓冲的接口在 `cap` 不够时返回"应该有多长"，不写半截。

## 判据

- `loment_domains_test::test_world_reference_packages`：47 项行为，与 Python 的
  预期逐字节相同（日历换算、复活节、时区、ISO 解析、相对时间、geohash、
  国旗、语言标签、电话、邮编、ISBN/EAN/IBAN/Luhn、slug、转写、人名、英文数字、
  罗马数字）。
- 孪生：19 个新模块 + 门面 `world.lomt` 共 20 份产物，参考实现与自举实现逐字节相同。
- 计数：`world` 3 → 22 个 `.lomt`，整棵树 227 → **246** 个文件。

## 过程中修掉的真缺陷

- `dateparse` 的 `ok` 标志在成功路径上从未置 1（日期永远返回 0）。
- `isbn10_to_13` 漏算 `978` 前缀的三位权重（校验位差 2）。
- `postal` 把 9 位 ZIP+4 挡在"长度 ≤ 8"之外。
- `words` 的序数词特例比较的是**数字字符**而不是单词首字母。
- `translit` 没处理带重音的希腊字母（`ή` 原样漏出）。
- `geohash` / `timeago` 内部前缀与 `geo` / `translit` 撞名（平命名空间）。
