# 229 · 逐站点说出"它为什么落到那一层"

> 状态: **已落地**（2026-10-10）· 上游: `docs/210`（四层梯与 `gc_ladder`）、`docs/225` §4.③（议程里那三条空白之一）
> 一句话: `gc_ladder` 给的是一个**数**；这一篇给那个数**每一格的一句理由**，并且用一条
> **对账判据**把这份报告钉在编译器上 —— 不许它自己长出一套分类。

## 0. 为什么需要它

`docs/210` §3 的窄新颖面是"**GC 的组成是一个不读源码可判的数**"（Potato `gc_ladder`）。
那是一个**数**，而数是**不告诉你为什么**的：一个站点落在 `L3`，可能是五种完全不同的原因，
**修法各不相同**。

`docs/214` §5 假设 2 的代价那一格写的正是这件事：**「用户要写界与作用域；曲线陡」**。
而 §7 **证明**了"自动改写"不可能 ⇒ **剩下的价值全在"把为什么说清楚"这一步上**。

## 1. 它是什么

`tools/loment_gc_why.py` —— 一份**只读参考实现**的报告器：

```
  python tools/loment_gc_why.py FILE [--json]
```

对每一个 `alloc` 站点输出：**落在哪一层**、**为什么没落更高**。

```
     15  L0 `a`
     18  L1 `b`   （L0 没收：尺寸不是字面量（L0 要求字面量，命名常量也不行））
     22  L2 `c`   （L0 没收：尺寸不是字面量）
     26  L3 `d`   ← 尺寸不是字面量
```

`L3` 的**具名原因**是一张**封闭的表**（`REASONS`）—— 形状不合 / 形参 / 尺寸不是字面量 /
尺寸为 0 / 外逃 / 被声明不止一次 / 既不在纪元里也不在定活名单里。每条都指得到"用户该改哪儿"。

## 2. 它凭什么可信：**对账**

它**不自己发明分类** —— 它复用 `lomentc` 的那几张表（`Func.l0` / `Func.l1` / `Return.l1` /
`Loop.l2`）与**同一条 rung 顺序**（L0 → L2 → L1 → L3），并且有一条判据钉着：

> **判据 A（对账）**：语料里每一份模块，本工具数出来的四层直方图**必须等于**
> `lomentc._count_gc_ladder()` 的四个数。

**漂了就是红的。** 这一条与 `tools/loment_gc_surface.py`（那把"证明面有多宽"的尺子）是
同一种做法：**尺子自己也要有判据钉住**。今天它跑 35 份模块逐份相同。

## 3. 写它的时候，梯子的语义**纠正了我两次**

两条都留在这里，因为它们是**梯子的真语义**，而文档里没有一处直说：

| 我以为 | 实际 | 为什么 |
|---|---|---|
| "尺寸不是字面量" ⇒ 落 `L3` | **落 `L1`** | `L1`（定活）的资格与 `L0` **是同一条**（`_ptr_only_uses`），它**不要求尺寸是字面量**。所以那句话只说明 **`L0` 没收**，不说明没人收 |
| 把指针传给一个**不碰它**的用户函数 ⇒ 外逃 | **不外逃，照进 `L0`** | `docs/210` §7 那次 deref-only 放宽：首参**只被安全地透传**（含"压根不用"）⇒ 调它等于调内建 |

第一条直接改了这个工具的形状：**`l0_refused` 对每一行都给**（不是 `L3` 才给）——
一块落在 `L1` 而没上栈的程序，用户要看的正是那一句。

## 4. 判据（四条，全在 `tools/loment_gc_why_test.py`）

| # | 判据 | 证伪方式 |
|---|---|---|
| **A** | **对账**：直方图 == `_count_gc_ladder()` | 任何一份模块上不等 ⇒ 报告开始说谎 |
| **B** | 理由**完备**：`L3` 行必在 `REASONS` 里，其余行必无理由 | 出现表外的理由 ⇒ 分类不封闭 |
| **C** | **一对（三份）程序**只差一行：`L0` → `L1` → `L3`，理由分别是"无"、"L0 因尺寸不是字面量没收"、"外逃" | 落层或理由指着别处 ⇒ 报告指不到点上 |
| **D** | **非空转**：语料上四层**都**出现过非零 | 某一层恒为 0 ⇒ 这套东西测的是一个不会发生的输入 |

判据 D 写起来也红过一次：**唯一一份 alpha 语料在子目录里**（`examples/gc_ladder/main.lomt`），
而 `examples/*.lomt` 是**单层 glob** —— 够不到它，于是语料里的 L0/L1/L2 恒为 0。

**L0.5**（`docs/210` §2.10）也进直方图（`RUNGS` 五格），但判据 D 仍只要求原四层非空 ——
这份语料里还没有"一个函数两处以上 L0 站点"的形状，L0.5 恒为 0 是**语料**的事实，不是
报告的缺口；L0.5 自己的非空转由 `lomentc_test::test_l0_5_region_rule` 钉住。

## 5. 没做的（写明）

* **只读参考实现。** 自举侧要出这份报告得先有它自己的孪生（`checker.lomt` / `codegen.lomt`），
  那是下一格。**现在两边不会漂**，因为只有一边在说。**但要记住这一条**：一旦自举侧也出报告，
  判据 A 要跟着变成**两份报告逐字节相同**。
* **没有"最小可证的界"。** 这份报告说"尺寸不是字面量"，**不说**"n ≤ 4096 就够了" ——
  后者要**值域分析**（"`n` 从哪来、上界是多少"），是另一件事。
* **不进产物、不改 Potato。** 它是**给人读的**，不是形式对象的一部分。要不要让它进
  （例如 `gc_why` 一节），等有第二个人要用它的时候再说 —— `docs/210` §3 那条纪律：
  进产物的东西必须**不读源码可判**，而"为什么"是散文。

## 6. 我不主张

1. **不主张这张原因表完备**：它按 `_l0_promotable` 那几道闸的**原顺序**给出**第一条**挡住的
   原因 —— 同时命中两条时，修了第一条会露出第二条。**这是有意的**（修法是迭代的），
   但它不是"全部原因"。
2. **不主张它能替人做决定**：`L3` 常常是**对的**（那块本来就该交给收集器）。
   这份报告的用途是**缩短"为什么这么慢/这么占"的定位时间**，不是"把 L3 消掉"。
3. **不主张它已经量过规模**：今天的尺度是 35 份仓内模块，其中只有 1 份 alpha 语料
   （L0=1 · L1=1 · L2=1 · L3=20）。**真实语料上的样子还没见过** —— 这与
   `docs/225` §4.② 那件待办是同一件事的两面。
